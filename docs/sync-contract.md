# 多设备 WebDAV 同步协议

本文件描述多台 Android 手机共同使用的 v1 数据格式。同步内容为记录原文、日程、附件及课表学期；AI/WebDAV 密钥、界面偏好、设备日历事件 ID、提醒设置和处理队列留在本机。局域网浏览器调用所连接手机的 API，共用手机数据与同步身份。

## 记录

对象 ID 为 `task_<UUID>` 或 `term_<学年>_<季节编号>`，只含字母、数字、下划线和短横线。每个对象使用版本向量和多值寄存器；并发修改保留全部版本，用户选择后产生一个覆盖已知版本的新版本。删除也是有版本的墓碑，不以云端文件缺失判断删除。

任务 payload：

```json
{"kind":"task","rawText":"原文","source":"manual","createdAt":0,"status":"ready","linkText":"","candidates":[{"id":"UUID","title":"事项","startAt":null,"endAt":null,"zone":"Asia/Shanghai","location":"","description":"","category":"event","allDay":false,"endAutoGenerated":false,"uncertainty":0}],"attachments":[{"sha":"64位小写SHA256","name":"文件名","mime":"image/jpeg","size":0,"image":true}]}
```

任务状态只同步 `ready`、`needs_review`、`failed`；正在处理的本机任务等处理结束后才参与同步。候选 ID 跨设备稳定；本机提醒及日历关联按该 ID 保存。附件内容按 SHA-256 寻址，单个附件上限 20 MiB。

学期 payload：`{"kind":"term","index":0,"document":{...}}`。document 与现有 TimetableStore 编码相同，含 format/name/ics/importedAt/zone/plan/enabled/classification；enabled 仅含该学期 index。每个学期单独合并，选择中的学期不跨设备。原始 ICS 与学期边界保留。

## 传输与故障处理

WebDAV 根目录为用户配置地址下的 `ChronaSync/v1`。`heads/<device UUID>.json` 为该设备已知的完整寄存器集合；`blobs/<sha>` 为不可变附件。先上传附件，再用 ETag 条件写发布设备 head。失败不得清空本地记录或覆盖其他设备 head。每个 head 最大 32 MiB，只有本设备可写自己的 head。

先下载并校验所有 head，再合并；下载所需附件并校验 SHA-256 后才应用本地。并发版本暂不替换本机正在使用的记录，交由冲突界面选择。Android 日历绑定记录遇到远端修改/删除时要求在手机上确认处理，禁止因同步直接创建、修改或删除系统日历事件。

Android 完整备份恢复时，在同一同步互斥锁内清除设备 ID 和数据库中的同步映射、关闭自动同步，防止恢复到另一台设备后共用写入身份。恢复的任务会重新建立身份，手动同步时可能与云端旧记录重复；恢复结果和同步设置都会提示。正常离线重连保留身份与墓碑，不执行此重置。
