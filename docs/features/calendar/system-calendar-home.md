# 系统日历与日程来源

## 全局来源和页面开关共同生效

全局来源设置管理每本系统日历、导入课表及启用的学校课表。首页、日历、小组件和提醒各自保留系统日程开关；开关只决定是否读取真实系统日历，不限制本地课表。读取入口统一应用来源过滤和权限，关闭只影响显示与投递，不删除原始数据。

首页及日历／周日程共享操作胶囊中的系统日程开关，以图标从次要色切到主题色表达启用状态，不增加选中背景。按压复用同组其它按钮的公共填充高光，沿胶囊边界裁切，不单独绘制圆形涟漪。点击区域、整组放大、权限请求及无障碍开关状态保持不变。

开启学校功能是展示学校入口和缓存的前提，规则见[折姜星辰](../zju/zju-services.md)。课程聚合与来源优先只影响展示；实体合并另走[确认流程](../schedules/candidate-merge.md)。

## 读取、去重与交互

系统内容由后台有界、可取消的 `CalendarContract` 查询获取。快照绑定时间窗口、权限及来源；过期或被取消的结果不得回写。普通日期与全天 UTC 日期分别处理，保留重复事件的实际实例。

本地已写入的系统副本按关联身份排除，再按统一匹配规则组合外部来源，避免重复显示或吞掉整组。同名但时间或地点不同的事项不能仅靠标题合并。

来源查看支持全部与按周、分页与只读详情；查看已关闭普通来源不自动启用它。来源开关、读取权限和日历 ID 以本机为准，备份与换设备处理见[备份范围](../data/backup-coverage.md)。手动写入本地课表是生成副本，非持续同步，见[课表与来源](../zju/zju-services.md#课表与来源)。

课程关联预览中的「选择主来源／保持独立／取消」与来源选择弹层共用无边框菜单行，仅以相邻项分隔线区分，保留原确认、撤销及取消语义。
