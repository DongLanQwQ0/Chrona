# vivo 原子岛日程提醒

**目前每台支持的 vivo / iQOO 手机首次启用拾时原子岛通知，都需要用电脑通过 ADB 配置一次。配置只保存在执行过的手机系统里，不随 APK 分发；只安装软件无法自动完成。** 配置成功后日常使用无需电脑或保持 USB 调试。Windows [一键配置包](https://github.com/DongLanQwQ0/Chrona/releases/download/vivo-setup-0.15.42/Chrona-vivo-setup-0.15.42.zip)包含专用辅助程序及 ADB，具体步骤见[首次配置说明](../../../tools/vivo/README.md)。

在已完成本机配置的 vivo 设备上，Chrona 默认在日程开始前30分钟发送原子通知；Chrona 活动配置了更早的提前提醒时，从该提醒时刻出现。提醒使用专属场景 `CHRONA_AGENDA`，包含标题、时间和地点。是否读取系统日程由设置中的提醒选项独立控制。

2026-10-13 已在用户手机上完成专属场景注册，并取得原子岛实际显示截图。注册后的发送以普通应用身份进行，不需要持续连接 ADB。首次点击岛展开卡片，展开后点击卡片进入详情，用户已确认此交互完善。

自定义卡片包含主题色图标、地点、剩余时间、实心端点进度条，以及两端HH:mm时间之间的跑马灯。开始前从实际首次通知时刻累计到日程开始；活动开始后切换为活动进度，其它类别显示已开始，最多保留3分钟。弹幕复用小组件文字库，间隔显示下一件事；长文字由系统滚动，背景可选模糊壁纸或流动极光。最多三条提醒，每条独立隐藏和延后。

倒计时由实际目标时间重新计算，剩余秒数需要按秒持续更新，显示限制为非负。完成／确认动作接入统一状态管道，撤销后按当前提醒窗口恢复显示。已有真机勾选和秒数更新证据，但不代表所有系统形态和后台条件都已覆盖，具体版本见 [验证记录](../../validation-history.md)。

## 胶囊限时完整显示（0.15.41）

- 目标行为：进入桌面后胶囊完整显示30秒；点击胶囊展开原生大卡片时，从点击重新计60秒。点空白立即收起大卡片，但胶囊保持较长尺寸直到该60秒结束，再只显示前两个字。计时仅影响胶囊，不控制大卡片开关。
- 在通知与提醒设置的「原子岛 → 胶囊计时」中打开系统无障碍设置，由用户启用「原子岛胶囊计时」。该服务识别实际桌面进入及Chrona胶囊展开，分别建立30秒和60秒窗口；新出现的提醒也有30秒阅读窗口。到期胶囊仅显示标题前两个字，移除时间文字，保留图标；完整内容仍在展开卡片和通知中。
- 点击胶囊由系统原生展开卡片，点击卡片外空白立即收起；不使用强制展开，也不替换原详情入口。服务只观察窗口包名及vivo原子岛宿主中带有Chrona标记的标题，不执行点击／手势，不读取其它应用正文，不保存或上传屏幕内容。可在系统无障碍设置中停用。
- 统一由`AtomicCapsuleController`投影普通更新与秒级更新，刷新不续时，不接管系统点击，不主动展开卡片。过时的应用点击广播不处理。
- 计时使用单调时钟，持久保存并按开机身份隔离，进程在窗口内恢复沿用原期限。未启用辅助服务时沿用亮屏30秒；进程缺席而错过亮屏、恢复时所有旧窗口已过期，则补一次30秒阅读窗口。启用服务后以实际桌面事件为准，不用亮屏或进程恢复假定已进入桌面。作业十分钟期限与未读红点不变。
- 活跃进程以定时任务触发边界，同时交付系统闹钟供进程退出后恢复。未授予精确闹钟权限时，进程退出后的系统触发可能迟于30/60秒；不额外申请权限或保持唤醒锁。

### 当前固件的收起过渡仍有限制

2026-10-23 真机录屏确认，当前OriginOS宿主从大卡片收起时先经过约200ms窄黑胶囊，再进入内容实际宽度。当前手机`SystemUIPlugin.apk`的状态机将展开态4经中间态1转入胶囊态2／3；中间态使用系统资源固定宽度，动画时长200ms，结束后才重新生成左右内容。展开期间更新通知也不重建收起用的左右视图。

跳过应用350ms合并刷新、直接投递最新通知快照的候选仍被真机反证，已撤回；不能把最终显示完整称为“无闪回”。已检查的通知协议未提供跳过该中间态的入口。不使用强制展开／关闭、更改全局系统动画或修改系统宿主来掩盖这段过渡；当前尚未满足用户要求的连续收起效果。证据见验证记录。

最初候选的点击广播加`island.superx.forceShowCard`方式已被真机反证并撤回。当前辅助服务已在授权手机观察到原生点击并建立60秒期限；USB连接状态下，原生点击59／61秒、卡片跨65秒保持、点外部立即关闭及正式服务自动秒级更新已有有效证据。后续home-29／31帧均为精简，不用于签收桌面边界；无线5／10秒测试候选已验证点击＋8秒完整、＋11.5秒精简。完全断开ADB后的独立运行仍未单独验收，具体候选与证据范围见[验证记录](../../validation-history.md)。

0.15.41紧凑候选将卡片外层垂直内距改为8dp，标题与右侧48dp完成操作共行；保留字号，长标题自然换行。摄像头基础安全带40dp，仍优先采用真实cutout下缘加4dp；不改变胶囊计时或原生开关。短卡、320dp／1.5字体长卡实际RemoteViews及vivo最终画面已保存，后续自动重复提示改动不改变这些布局。

## 每台手机的首次配置

此工具只为当前连接的手机配置 Chrona 专属场景。生产 APK 不含场景注册代码，也不取得系统权限。配置工具借用已授权 ADB 的临时 `STATUS_BAR_SERVICE` 身份执行注册，立即撤掉身份，再以普通应用身份读回确认；不会修改已有的 `METTING` 或其它场景的应用名单。

0.14.33 的提前提醒有独立总开关、Chrona原子通知开关、系统日程原子通知开关及系统来源开关。系统来源关闭时完全不提醒系统日程，优先于系统原子开关。原子开关关闭或场景不可用时，使用普通常驻提醒；更换形式先清理旧卡片。首页与日历显示开关统一入口位于设置中的“系统日程”，原页面开关保留，显示偏好不影响提前提醒。

0.14.34补齐主题配色的地点图标，收紧卡片留白与行间距，保持标题字号及两行显示。弹幕区域按字体高度适配，保留最小20dp高度。

0.14.35为展开原子岛提供独立布局：顶部两侧显示图标与剩余时间，中间留空，完整标题放到摄像头下方。读取设备顶部挖孔下缘，必要时补足4dp安全间距，普通通知保持原布局。最终避让仍需真机验证。

0.14.36在距离开始（或活动结束）剩余两分钟时，将收起胶囊的固定时刻切换为系统秒级倒计时。非活动日程开始后显示“已开始”，最多三分钟关闭；活动继续显示进度直至结束。通知超时、下一次闹钟和数据库候选查询共用同一期限，刷新不会延长这三分钟。

先安装 GitHub 正式版拾时，等待解析和同步结束，再按[首次配置说明](../../../tools/vivo/README.md)解压配置包并双击 `Enable-VivoAtomic.cmd`。Windows 需 PowerShell 7，配置包已包含 ADB。高级用法：

```powershell
pwsh -File .\Configure-VivoAtomicScene.ps1 -Mode Enable
```

脚本自动识别单台已授权的实体手机，多台时需 `-Device '序列号'`，也可用 `-Adb '你的adb.exe绝对路径'`。工具只安装专用辅助 APK，运行专属场景配置并以普通身份检查结果，移除本次新装的辅助程序；不修改日程记录、不打开日历页面、不操作其它应用。`-Mode Status`可查询当前状态。

关闭该专属场景：

```powershell
pwsh -File .\Configure-VivoAtomicScene.ps1 -Mode Disable
```

关闭会使自有场景和包开关变为 false，保留一条停用的自有场景配置。配置失败不能当成已启用，工具会报错。成功注册也不单独证明已显示原子岛，仍应观察设备实际通知。

此接口是 vivo 隐藏接口，具体固件可能不提供或拒绝调用。本机实验不等于官方准入，也不能推广为所有 vivo 设备都免审核。正式第三方接入要求以 [vivo 接入指导](https://dev.vivo.com.cn/documentCenter/doc/894) 为准。
