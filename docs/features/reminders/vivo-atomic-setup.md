# vivo 原子岛日程提醒

在已完成本机配置的 vivo 设备上，Chrona 默认在日程开始前30分钟发送原子通知；Chrona 活动配置了更早的提前提醒时，从该提醒时刻出现。提醒使用专属场景 `CHRONA_AGENDA`，包含标题、时间和地点。是否读取系统日程由设置中的提醒选项独立控制。

2026-10-13 已在用户手机上完成专属场景注册，并取得原子岛实际显示截图。注册后的发送以普通应用身份进行，不需要持续连接 ADB。首次点击岛展开卡片，展开后点击卡片进入详情，用户已确认此交互完善。

自定义卡片包含主题色图标、地点、剩余时间、实心端点进度条，以及两端HH:mm时间之间的跑马灯。开始前从实际首次通知时刻累计到日程开始；活动开始后切换为活动进度，其它类别显示已开始，最多保留3分钟。弹幕复用小组件文字库，间隔显示下一件事；长文字由系统滚动，背景可选模糊壁纸或流动极光。最多三条提醒，每条独立隐藏和延后。

倒计时由实际目标时间重新计算，剩余秒数需要按秒持续更新，显示限制为非负。完成／确认动作接入统一状态管道，撤销后按当前提醒窗口恢复显示。已有真机勾选和秒数更新证据，但不代表所有系统形态和后台条件都已覆盖，具体版本见 [验证记录](../../validation-history.md)。

## 胶囊限时完整显示（0.15.41待真机验收）

- 每次亮屏后完整显示30秒；亮屏期间新出现的提醒也有30秒阅读窗口。随后顶部原子岛仅显示标题前两个字，移除时间文字，保留图标；完整标题、时间、地点及正文仍在展开卡片和通知中。
- 点击胶囊时重新给予60秒完整窗口，并请求系统展开原卡片；窗口从点击广播接收时刻起算，后台排队不延长。再次点击重新计时，单纯收起不重新计时。卡片空白区域继续进入原详情，原有完成、关闭等操作保留。
- 统一由`AtomicCapsuleController`投影普通更新与秒级更新，刷新不续时，也不反复展开卡片。点击使用不可变PendingIntent的URI通知身份；已关闭或被其它事项替换的旧点击不恢复通知。
- 计时使用单调时钟，持久保存并按开机身份隔离。进程在窗口内恢复沿用原期限；进程缺席而错过亮屏、恢复时所有旧窗口已过期，则从恢复时补一次30秒阅读窗口。作业原子通知有效期内复用已有前台更新服务观察屏幕，通知结束即停止，不修改作业十分钟期限与未读红点。
- 活跃进程以定时任务触发边界，同时交付系统闹钟供进程退出后恢复。未授予精确闹钟权限时，进程退出后的系统触发可能迟于30/60秒；不额外申请权限或保持唤醒锁。

这份待验代码将原子岛点击交给应用计时，再使用本机固件解析的`island.superx.forceShowCard`展开。正常收起不依赖受系统级权限保护的`ISLAND_STATE_CHANGED`。实际点击展开、两字宽度及通知图标避让需在vivo上确认；代码构建和离线检查不代表这些OEM行为已经验收。

## 个人开发设备的一次性配置

这是一项显式的本机开发配置，会持久增加仅包含 Chrona 的场景。生产 APK 不含场景注册代码，也不取得系统权限。配置工具借用已授权 ADB 的临时 `STATUS_BAR_SERVICE` 身份执行注册，立即撤掉身份，再以普通应用身份读回确认；不会修改已有的 `METTING` 或其它场景的应用名单。

0.14.33 的提前提醒有独立总开关、Chrona原子通知开关、系统日程原子通知开关及系统来源开关。系统来源关闭时完全不提醒系统日程，优先于系统原子开关。原子开关关闭或场景不可用时，使用普通常驻提醒；更换形式先清理旧卡片。首页与日历显示开关统一入口位于设置中的“系统日程”，原页面开关保留，显示偏好不影响提前提醒。

0.14.34补齐主题配色的地点图标，收紧卡片留白与行间距，保持标题字号及两行显示。弹幕区域按字体高度适配，保留最小20dp高度。

0.14.35为展开原子岛提供独立布局：顶部两侧显示图标与剩余时间，中间留空，完整标题放到摄像头下方。读取设备顶部挖孔下缘，必要时补足4dp安全间距，普通通知保持原布局。最终避让仍需真机验证。

0.14.36在距离开始（或活动结束）剩余两分钟时，将收起胶囊的固定时刻切换为系统秒级倒计时。非活动日程开始后显示“已开始”，最多三分钟关闭；活动继续显示进度直至结束。通知超时、下一次闹钟和数据库候选查询共用同一期限，刷新不会延长这三分钟。

先安装对应版本 Chrona，连接已授权 ADB 的手机，再解压发布附件 `Chrona-vivo-setup-0.14.36.zip`。使用 PowerShell 7：

```powershell
pwsh -File .\Configure-VivoAtomicScene.ps1 -Device '手机IP:连接端口' -Mode Enable -TestApk .\Chrona-device-checks.apk
```

ADB 未在 PATH 中时，使用 `-Adb '你的adb.exe绝对路径'`。工具只安装对应的测试 APK，运行专属场景配置并检查结果，不修改日程记录、不打开日历页面、不操作其它应用。

关闭该专属场景：

```powershell
pwsh -File .\Configure-VivoAtomicScene.ps1 -Device '手机IP:连接端口' -Mode Disable -TestApk .\Chrona-device-checks.apk
```

关闭会使自有场景和包开关变为 false，保留一条停用的自有场景配置。配置失败不能当成已启用，工具会报错。成功注册也不单独证明已显示原子岛，仍应观察设备实际通知。

此接口是 vivo 隐藏接口，具体固件可能不提供或拒绝调用。本机实验不等于官方准入，也不能推广为所有 vivo 设备都免审核。正式第三方接入要求以 [vivo 接入指导](https://dev.vivo.com.cn/documentCenter/doc/894) 为准。
