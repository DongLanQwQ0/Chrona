# 课堂总结

在「折姜星辰 → 课堂总结」选择一节已就绪的智云回放，获取字幕与截图，再生成笔记。使用已保存的学校账号与 AI 服务；第一版按单节课堂手动生成。

## 按周或按列表选课

课表默认本周，可切换上周、下周或跳转日期。按学校返回的真实开始时间排列；接口没有结束时间时不推算时长。未来课堂和准备中的课堂保留显示，不能生成总结。

列表按最近到以前排列，每次显示 50 条并可继续加载。课程目录先完整读取再排序，避免跨课程分页打乱时间顺序。已缓存目录与历史总结可以离线查看，刷新失败保留已有内容。

## 先准备素材，再确认上传

素材准备从智云读取带时间的字幕与截图。应用在本机缩小截图进行相邻画面比较，接近的连续画面保留较晚一张；分析时使用清晰图。该步骤不下载 OCR 模型，也不增加 OCR SDK。

生成前显示字幕状态、原始截图数、去重候选数和图片分析上限。默认最多 20 张，可调整；预算小于候选数时按时间覆盖整节课堂，保留最后一张。这个筛选用于控制图片量，不能保证覆盖每个细微板书变化。

确认后，本节字幕和选中的图片发送到当前 AI 服务。选择纯文字时不上传图片；不支持图片的模型需明确改用纯文字或更换服务，不会静默重发。学校密码、Cookie 和登录跳转不会发送给 AI。

## 分段整理，失败可续跑

字幕和图片按时间顺序分段，逐段保存笔记，再合并重点概览。已完成的部分可以先查看；失败重试复用素材和相同配置下已完成的分段。更换模型、推理设置或图片上限后重新整理，不拼接不同配置的结果。

笔记按主题保留概念、公式和例题，附字幕来源时间及实际分析的图片。字幕存在识别或对齐错误时，笔记仍需要结合课程核对。作业、考试等课堂安排只作为建议，用户主动确认后进入记录编辑流程。

## 导出含图片的 Markdown

导出结果是 ZIP：

```text
课堂总结.md
sources.md
images/
  image-…jpg
```

解压后打开 `课堂总结.md`，图片使用相对路径，来源时间链接到 `sources.md`。未完成的笔记会标记进度。导出的图片与字幕属于课程资料，应按学校和教师的分享要求保存、使用。

课堂缓存和历史按本机匿名账号隔离；关闭折姜星辰后停止学校访问并隐藏入口。课堂资料不参与 WebDAV 同步或通用完整备份，需要长期保存时单独导出 Markdown ZIP。

## 实现入口

- `ClassroomClient`：智云只读目录、字幕、截图与权限检查，认证复用 `ZjuClient`。
- `ClassroomStore`：账号隔离与原子缓存。
- `ClassroomImages`：本地比较、预算选图与清晰图转换。
- `ClassroomSummary`：分段、引用校验、进度检查点与合并。
- `ClassroomExport`：Markdown、字幕来源与图片打包。
- `ChatCompletionClient.complete`：复用现有 AI 传输、推理设置、超时与取消，不使用日程提取 schema。
