# 折姜星辰

在「设置 → 日程处理 → 折姜星辰」保存学号和密码，再打开「折姜星辰」。页面保留一行「浙江大学专属功能」说明。保存账号与退出账号并排放在账号卡片内。作业同步与提醒、课表同步可以分别开关；点击标题栏右上角圆形刷新按钮立即同步并查看结果。

「课堂总结」可按周课表或倒序列表选择智云回放，利用字幕和截图生成笔记，并导出带图片的 Markdown ZIP。操作与数据范围见[课堂总结](classroom-summary.md)。

## 查看考试安排

打开「折姜星辰 → 考试安排」，直接查询本科教务已公布的考试。卡片显示课程、考试类型、官方日期与星期、起止时间、考场和座位号；期中使用独立的时间、考场和座位字段。缺少考场或座位时显示待公布，无法识别的时间原文保留，不猜日期。

进入时更新，也可点击右上角刷新。先显示本账号的本机缓存，完整分页成功后统一替换；失败保留旧数据并显示原因。即将进行的考试按时间排列，已结束的排在后面；不依赖学在浙大的“活跃学期”标记，避免学期结束时漏掉仍未进行的考试。教务没有公布时间的课程不编造考试记录。

本页复用二级阅读页标题、圆形刷新和卡片，整页滚动，横屏上滑可将标题移出屏幕。首批缓存或查询结果到达后呈现一次，后续刷新不重播。旋转保留正在进行的查询，离开页面取消本页请求；关闭服务、退出或切换账号后隐藏旧数据，旧请求不落入新账号缓存。退出账号清除考试缓存，系统也可回收该可重新获取的缓存。

考试查询仅在本页执行，不新增后台同步开关，不调用AI，也不自动创建日程或写入系统日历。凭据继续由原Android Keystore与短期内存Cookie管理。接口字段参考[fiz的考试查询](https://github.com/CrazySpottedDove/fiz/blob/dev/src-tauri/src/test.rs)，接入代码独立实现。

「日程 → 筛选 → 类型 → 考试」只读显示本账号已获取的教务考试，全部类型也包含考试；网页日程保持一致。可按日期、关键词与状态筛选，点击查看考场和座位，不加入手动／AI类别，也不参与本地批量删除和写入。缓存刷新、账号及来源边界见[日程浏览合同](../schedules/schedule-browser.md)。

## 作业自动整理到同一个收件

学在浙大的已发布作业进入「作业」，直接读取官方截止时间，默认不调用AI。无截止时间的作业保留为待安排，逾期作业继续保留。

「新作业自动排程」默认关闭；开启前确认将作业标题、内容和截止发送到当前AI服务，并授权直接应用可修改的执行时间。只处理开启后新接收、未完成、有未来截止且尚无个人执行时间的作业；不会追溯重排已有作业。复用日程AI的工作时段、自定义偏好、全周期排期和时间依据，按工作量安排并留修改／提交缓冲。

结果只更新原作业的执行起止和真实存疑程度，不另建日程、不改官方截止、正文、分类、提醒或身份。详情在当前仍沿用该时段时显示「AI建议」；手工改动后不把新时间继续标为该建议。提交结果前重验账号、绑定代次、官方快照及个人字段，处理期间的编辑、完成、删除或关闭授权均不覆盖。学校同步先保存并通知，之后每轮至多整理一项；无完整工作窗口或AI失败时保留原截止，不硬挤到截止前。排程不会重新解析整个作业收件。

每次实际请求保存独立解析审计，关联原作业及稳定身份，保留模型时间依据、建议与实际应用结果，授权政策记为`auto_authorized`；授权自动应用不代表推测成为确定事实。未开始队列可在后续正常同步处理，未知结果不自动重发；完整恢复取消待排项，避免恢复旧备份重新调用AI。关闭开关取消队列与在途请求，重新开启也不重排旧项。

首页标题右侧的作业图标直接打开未完成作业筛选，最近作业同时计入首页待办。详情先读取本地数据，按需创建当前与相邻编辑页，不等待联网。标题使用「课程名 · 作业名」；旧标题在下一次成功同步时更新，保持同一作业及其历史。

- 同一作业重复同步只更新原项，保留个人执行时间、提醒、完成状态及日历关联。
- 有截止时间的未完成作业自动写入拾时的系统日历，默认使用截止时间起的一分钟标记；若自行安排执行时段，则使用该时段。没有截止或执行时间时不创建日历事件。已有本地作业也会补写，无需再次拉取学校数据。
- 缺少日历权限时在本地等待，可在本页点击「允许写入系统日历」授权；授权后自动补写。重复刷新不重复创建，已有事件随作业变更更新。
- 官方已提交时自动完成；普通内容更新不会撤销你手动完成的状态。无法识别提交状态时保留原状态并提示。
- 老师改变标题、正文或截止时间时记录变更，更新待办与关联系统日历。系统日历权限或写入失败时显示待更新，并在刷新时重试。
- 同步当前学期及本账号已追踪作业所属课程，跨学期后继续接收延期和提交状态更新。学校列表不再返回某课程时保留本地数据并提示。
- 在「作业更新记录」查看修改前后信息，每次加载 50 条，点击「加载更多」可查看更早记录；完整历史保存在本地数据库及完整数据备份中。
- 删除单项作业后普通同步不会再次生成。删除整个「作业」收件会关闭作业同步；之后只能在设置中明确重新开启。
- 关闭作业开关保留已有数据，停止该来源后续提醒。重新开启已删除收件会建立新的绑定，重新读取学校返回的已发布作业，已提交项仍按已完成处理。

## 课表与来源

「今天的安排 → 课表」可直接查看浙大课表。已保存账号且启用折姜星辰时默认显示学校缓存，也可切换「导入课表」或导入 ICS。学校课程按返回的原始学期分组，包含短学期；学期选择仅影响本页显示。课程详情只读，保留实际日期、地点和备注。

在课表页点击「刷新课表」同步；课表开关关闭时显示「启用浙大课表」，点击后启用并同步，总服务关闭时则进入学校设置。失败保留旧缓存，账号和缓存版本变化后重新读取。显示逻辑及导入规则见[本地课表](../calendar/course-timetable.md)。

作业详情中，课程／作业标题、内容、截止时间、类型和平台提交状态只读；个人执行时段、全天安排、地点、提醒及本地完成状态可调整。本地完成可撤销，但平台已确认提交的作业不能在本地重置。删除单项仍表示忽略；作业收件不能重新解析替换。源字段限制同时在存储编辑入口校验。作业卡片末尾一行提供「雪灾浙大M」「雪灾浙大」，分别打开手机站和可复制文字的网页站；关闭折姜星辰后隐藏入口。

学校作业详情隐藏「原始内容」「图片与文件」以及「重新解析」整组区域，连同背景和附件添加入口一起移除；已保存的原文和附件继续保留。普通收件详情的这些功能保持可用。

同步发现新增且未完成的作业时，使用现有 vivo 原子岛通道展示作业专用信息卡。熄屏收到时持久保存待亮屏状态，不设置通知超时；首次亮屏开始十分钟计时，亮屏时收到则立即开始。之后熄屏／亮屏、重复同步、部分完成及进程恢复不重新计算已经开始的十分钟。首次亮屏前连续发现的新作业合并保留，避免替换掉尚未查看的事项。卡片展示课程／作业标题、截止时间及正文；同批多项显示数量和其它作业标题。不显示地点、进度条或完成勾选。右侧 Lucide「×」关闭通知，只撤下本次提示，不改变作业完成状态。原子岛不可用的设备使用同一信息卡的普通通知；均遵守作业更新频道和系统通知权限。

新作业入库时，在同一数据库事务中保存独立的未查看标记。主页右上角作业图标显示红点；点击后进入未完成作业筛选，按实际列表排序定位该项所在分页，将行滚到屏幕中央并短暂高亮，实际展示后仅清除该项标记。多项新作业依次定位最新未查看项，仍有其它新项时保留红点；没有红点时保留原最近作业入口。通知关闭或到期不清除红点，重复同步不恢复已查看标记；已完成、删除或来源停用的项不出现在红点目标中。旧数据升级不额外标记为新作业。

普通通知折叠时使用系统原生标题／摘要；展开后标题与关闭键共用首行，正文在下方，避免把整张岛卡塞入折叠高度。同批多项的数量同时保留在折叠摘要与展开截止信息中，有截止时间时也不省略数量。原子岛继续保留摄像头安全头行、下方作业标题和数量。通知预览按行数省略长内容，点击打开完整作业详情。

提示期间，本地完成、平台确认已提交或删除作业后移除对应提示项；全部完成则撤下通知。批量提示仍有未完成项时更新剩余信息，沿用原到期时间，不重新计算十分钟；关闭来源或切换绑定也撤下旧提示。首页「全部待办」与折叠箭头之间的刷新按钮只刷新作业；学校设置的标题栏刷新仍同步所有已开启来源。

通知投递前保存作业身份与待亮屏状态，开始计时时同步保存绝对到期时间；进程结束后继续按同一身份处理完成与撤下。熄屏等待期间复用既有提醒服务监听真实亮屏广播，首次亮屏后由通知超时与原结束闹钟撤下；没有待亮屏作业或活动提醒时停止服务。系统拒绝后台服务启动时保留待展示状态并记录原因，后续应用唤起继续处理，不放宽系统权限。关闭同步清理通知状态。保存失败时不投递无法跟踪的新提示，不影响已同步作业及红点。

「日程来源 → 将课表写入系统日历」可选择导入课表、折姜星辰课表或两者，从本地缓存读取全部已保存学期（包括未启用学期），确认数量后写入 Chrona 系统日历。无需学校联网或 AI。相同标题、实际起止、全天状态、地点的课程先去重，两个本地来源冲突时保留学校备注；再次写入会扫描所有系统日历（包括显示开关已关闭的来源），已有相同实例则跳过，不修改其他软件的事件，不额外添加提醒。失败显示已写入数量，重试会跳过已完成部分。

课表写入是用户主动生成的系统日历副本；后续课程修改不会自动更新或删除该副本。关闭折姜星辰后不能选择其缓存，排队期间关闭也会停止学校课表写入。导出入口无需新增持久设置。

课表直接读取本科教务系统。内置 2026–2027 学年普通本科秋、冬、春、夏校历，包含单双周、13 节作息、假期与已公布调课。考试时间不会当成课程时间；没有确定日期的实践安排仅提示，不自动生成时间。

在「折姜星辰 → 校历」选择校区，维护学年、学期、授课截止、节次、停课日及补课，也可导入导出 JSON。海宁使用独立连续秋冬配置；若学院课表返回分段学期，需要填入对应分段。未知学年先补齐校历；2027 年尚未公布的调休需待学校公布后更新。学校在线接口仅提供学期边界，不提供完整停课及调课安排。

「设置 → 日程来源」可以分别启停导入课表、浙大课表以及每本系统日历。原首页、日历、小组件和提醒的系统日程开关保留，仅影响真实系统日历；读取本地导入课表和浙大缓存不要求系统日历权限。

点击来源行默认查看全部日程，每次加载 50 条；也可切换到按周查看并打开条目详情。系统日历的全部模式每个重复系列列一次，周模式列实际实例。日程数为零的来源隐藏；右侧开关单独启停，查看不会打开来源。未启用折姜星辰时，浙大来源、优先项、关联规则与缓存内容不显示，仅设置中的启用入口保留。

课程详情直接读取本地课表缓存。导入课程保留原备注；教务课表补充实际返回的教师、课程编号、选课课号、排课规则、节次及单双周信息，缺失字段不猜测。旧缓存在下一次成功课表同步时补齐。

重复项可选择优先来源。同起止时间、全天状态一致且地点与分组无冲突时，按保守规范化同名或明确课程编号匹配；甲乙、I/II、实验与理论保持区分。名称不同的课程可在「日程来源 → 课程关联」预览并选择主来源，也可手动关联、保持独立或撤销。关联按两来源分别确认，不自动传递到第三来源。

完全同标题、起止、全天状态和地点的来源实例默认合并展示，同源重复也适用。完全相同的标题只规范全半角、空白及大小写，不删教师、班级或课程阶段信息；空地点与非空地点有区别。优先保留所选主来源；未指定时稳定优先浙大、导入、系统日历，明确「保持独立」的关系保留。原始数据不删除，本地草稿的实体合并仍走「合并完全相同日程」确认流程。

来源页结合日历名称及重复排课结构提供提示，不自动关闭整本日历。混合日历中的其他活动保留。导入/API 课表不会再次自动写回系统日历。完整备份包含来源与关联配置；系统日历 ID 属于设备，换设备后应重新检查来源选择。

## 后台与账号安全

作业按五分钟、课表按三十分钟分别尝试更新，两类来源独立计算下次拉取时间。应用处于前台时持续检查到期来源；返回应用也会立即检查。后台使用联网约束的一次性 Job，结束后按最早到期的来源重新调度，避免周期 Job 的十五分钟下限将作业间隔抬高。实际执行仍受 Android 的休眠、电量管理和任务配额限制，五分钟是拉取目标间隔。工作时段内保持相同的五分钟目标。学校设置中的手动刷新同步所有已开启来源；首页作业刷新只请求作业。后台到期检查不会顺带重复拉取尚未到期的课表。

失败尝试同样按对应来源间隔重试，不在认证失败时立即循环。已取得的截止提醒通过现有本地通知/原子岛管道运行，不需等待打开应用。

作业和课表独立应用成功结果，一方认证失败时提示重新登录，不丢弃另一方已获取的数据。全部来源失败时保留本地缓存。凭据无法解密时可填写完整学号和新密码重新保存，也可直接退出账号；同一账号沿用已有作业身份与删除记录。

账号和密码通过独立 Android Keystore 加密保存在本机，Cookie 仅驻留一次请求会话内。学校凭据不进入 AI、日志、局域网数据、配置备份、完整数据备份或 WebDAV。其它设备可以同步普通作业结果，不会收到登录凭据；建议只在一台设备启用学校拉取。

验证码、多因素验证或登录失败会提示重新登录，不绕过验证。退出账号会停止同步、清除账号和课表缓存；作业历史保留。恢复完整备份后自动同步关闭，需检查账号及来源后重新开启。
