# 折姜星辰

在「设置 → 日程处理 → 折姜星辰」保存学号和密码，再打开「折姜星辰」。作业同步与提醒、课表同步可以分别开关；点击「立即同步」查看结果。

「课堂总结」可按周课表或倒序列表选择智云回放，利用字幕和截图生成笔记，并导出带图片的 Markdown ZIP。操作与数据范围见[课堂总结](classroom-summary.md)。

## 作业自动整理到同一个收件

学在浙大的已发布作业进入「作业」，直接读取官方截止时间，不调用 AI。无截止时间的作业保留为待安排，逾期作业继续保留。

首页标题右侧的作业图标直接打开未完成作业筛选，最近作业同时计入首页待办。详情先读取本地数据，按需创建当前与相邻编辑页，不等待联网。标题使用「课程名 · 作业名」；旧标题在下一次成功同步时更新，保持同一作业及其历史。

- 同一作业重复同步只更新原项，保留个人执行时间、提醒、完成状态及日历关联。
- 有截止时间的未完成作业自动写入拾时的系统日历，默认使用截止时间起的一分钟标记；若自行安排执行时段，则使用该时段。没有截止或执行时间时不创建日历事件。已有本地作业也会补写，无需再次拉取学校数据。
- 缺少日历权限时在本地等待，可在本页点击「允许写入系统日历」授权；授权后自动补写。重复刷新不重复创建，已有事件随作业变更更新。
- 官方已提交时自动完成；普通内容更新不会撤销你手动完成的状态。无法识别提交状态时保留原状态并提示。
- 老师改变标题、正文或截止时间时记录变更，更新待办与关联系统日历。系统日历权限或写入失败时显示待更新，并在刷新时重试。
- 同步当前学期及本账号已追踪作业所属课程，跨学期后继续接收延期和提交状态更新。学校列表不再返回某课程时保留本地数据并提示。
- 在「作业更新记录」查看修改前后信息，每次加载 50 条，点击「加载更多」可查看更早记录；完整历史保存在本地数据库及完整数据备份中。
- 删除单项作业后普通同步不会再次生成。删除整个「作业」收件会关闭作业同步；之后只能在设置中明确重新开启。
- 关闭作业开关保留已有数据，停止该来源后续提醒。重新开启已删除收件会建立新的绑定，重新读取学校返回的已发布作业，已提交项仍按已完成处理。

## 课表与来源

「今天的安排 → 课表」可直接查看浙大课表。已保存账号且启用折姜星辰时默认显示学校缓存，也可切换「导入课表」或导入 ICS。学校课程按返回的原始学期分组，包含短学期；学期选择仅影响本页显示。课程详情只读，保留实际日期、地点和备注。

在课表页点击「刷新课表」同步；课表开关关闭时显示「启用浙大课表」，点击后启用并同步，总服务关闭时则进入学校设置。失败保留旧缓存，账号和缓存版本变化后重新读取。显示逻辑及导入规则见[本地课表](../calendar/course-timetable.md)。

作业详情中，课程／作业标题、内容、截止时间、类型和平台提交状态只读；个人执行时段、全天安排、地点、提醒及本地完成状态可调整。本地完成可撤销，但平台已确认提交的作业不能在本地重置。删除单项仍表示忽略；作业收件不能重新解析替换。源字段限制同时在存储编辑入口校验。作业卡片末尾一行提供「雪灾浙大M」「雪灾浙大」，分别打开手机站和可复制文字的网页站；关闭折姜星辰后隐藏入口。

「日程来源 → 将课表写入系统日历」可选择导入课表、折姜星辰课表或两者，从本地缓存读取全部已保存学期（包括未启用学期），确认数量后写入 Chrona 系统日历。无需学校联网或 AI。相同标题、实际起止、全天状态、地点的课程先去重，两个本地来源冲突时保留学校备注；再次写入会扫描所有系统日历（包括显示开关已关闭的来源），已有相同实例则跳过，不修改其他软件的事件，不额外添加提醒。失败显示已写入数量，重试会跳过已完成部分。

课表写入是用户主动生成的系统日历副本；后续课程修改不会自动更新或删除该副本。关闭折姜星辰后不能选择其缓存，排队期间关闭也会停止学校课表写入。导出入口无需新增持久设置。

课表直接读取本科教务系统。内置 2026–2027 学年普通本科秋、冬、春、夏校历，包含单双周、13 节作息、假期与已公布调课。考试时间不会当成课程时间；没有确定日期的实践安排仅提示，不自动生成时间。

在「折姜星辰 → 校历」选择校区，维护学年、学期、授课截止、节次、停课日及补课，也可导入导出 JSON。海宁使用独立连续秋冬配置；若学院课表返回分段学期，需要填入对应分段。未知学年先补齐校历；2027 年尚未公布的调休需待学校公布后更新。学校在线接口仅提供学期边界，不提供完整停课及调课安排。

「设置 → 日程来源」可以分别启停导入课表、浙大课表以及每本系统日历。原首页、日历、小组件和提醒的系统日程开关保留，仅影响真实系统日历；读取本地导入课表和浙大缓存不要求系统日历权限。

点击来源行默认查看全部日程，每次加载 50 条；也可切换到按周查看并打开条目详情。系统日历的全部模式每个重复系列列一次，周模式列实际实例。日程数为零的来源隐藏；右侧开关单独启停，查看不会打开来源。未启用折姜星辰时，浙大来源、优先项、关联规则与缓存内容不显示，仅设置中的启用入口保留。

课程详情直接读取本地课表缓存。导入课程保留原备注；教务课表补充实际返回的教师、课程编号、选课课号、排课规则、节次及单双周信息，缺失字段不猜测。旧缓存在下一次成功课表同步时补齐。

重复项可选择优先来源。同起止时间、全天状态一致且地点与分组无冲突时，按保守规范化同名或明确课程编号匹配；甲乙、I/II、实验与理论保持区分。名称不同的课程可在「日程来源 → 课程关联」预览并选择主来源，也可手动关联、保持独立或撤销。关联按两来源分别确认，不自动传递到第三来源。

完全同标题、起止、全天状态和地点的来源实例默认合并展示，同源重复也适用。完全相同的标题只规范全半角、空白及大小写，不删教师、班级或课程阶段信息；空地点与非空地点有区别。优先保留所选主来源；未指定时稳定优先浙大、导入、系统日历，明确「保持独立」的关系保留。原始数据不删除，本地草稿的实体合并仍走「合并完全相同日程」确认流程。

来源页结合日历名称及重复排课结构提供提示，不自动关闭整本日历。混合日历中的其他活动保留。导入/API 课表不会再次自动写回系统日历。完整备份包含来源与关联配置；系统日历 ID 属于设备，换设备后应重新检查来源选择。

## 后台与账号安全

后台约每 30 分钟尝试更新，打开应用时过期数据也会刷新；实际运行受 Android 后台限制。已取得的截止提醒通过现有本地通知/原子岛管道运行，不需等待打开应用。

作业和课表独立应用成功结果，一方认证失败时提示重新登录，不丢弃另一方已获取的数据。全部来源失败时保留本地缓存。凭据无法解密时可填写完整学号和新密码重新保存，也可直接退出账号；同一账号沿用已有作业身份与删除记录。

账号和密码通过独立 Android Keystore 加密保存在本机，Cookie 仅驻留一次请求会话内。学校凭据不进入 AI、日志、局域网数据、配置备份、完整数据备份或 WebDAV。其它设备可以同步普通作业结果，不会收到登录凭据；建议只在一台设备启用学校拉取。

验证码、多因素验证或登录失败会提示重新登录，不绕过验证。退出账号会停止同步、清除账号和课表缓存；作业历史保留。恢复完整备份后自动同步关闭，需检查账号及来源后重新开启。
