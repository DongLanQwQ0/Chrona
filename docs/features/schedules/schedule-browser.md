# 日程、收件与日历浏览

操作说明见[使用指南](../../user-guide.md)。本页记录开发时需要共同维护的数据、状态和页面契约。

## 列表与筛选

待办与作业的有效截止时间依次取明确截止时间、执行结束时间、执行开始时间；全部为空时保持待安排。截止显示、「今日截止」筛选和提醒继续使用该值，不回填原始截止字段，学校截止更新保留来源含义。

逾期单独比较执行安排与提交截止：有结束时间时取结束，只有开始时取开始；明确截止更早则取较早时刻，没有执行时间则按明确截止。当前时间严格超过该时刻且尚未完成，才列入逾期；正在执行、恰好到边界、无时间、已完成、活动和记录不计入。首页数量、逾期筛选／排序／分组、原生状态与网页使用同一含义；重复日程按当前实例的改期、完成状态重新判断。派生值不改原始字段、提醒锚点或其他截止排序。

普通待办（`task`）的原始开始、结束均为空且明确截止存在时，日程列表、首页时间线、原生日历与小组件统一使用截止前 30 分钟至截止的缺省执行区间；跨午夜按区间相交查询和起始日期分组。这是只读的显示／查询区间，不回填数据库、详情编辑字段或同步原始字段；修改截止即重新计算，清空截止即撤销。已有用户或 AI 执行安排、仅缺一个起止字段、活动、记录和学校作业保持原状；学校仅截止作业继续显示截止时间点。缺省区间按截止的真实瞬间计算，即使原始 `allDay` 为真也按定时区间显示，原始标记仍保留。截止筛选、逾期判断和提醒仍以截止为锚；系统日历写入及重复 RRULE 保持原合同。

日程按日期分组，提供待处理、待安排、历史、全部；类型筛选为全部、活动、待办、作业、考试。考试仅来自已启用、已配置的折姜星辰教务考试缓存，全部类型也包含考试；不按标题判断，手动编辑、AI解析和持久类别仍只保留活动、待办、作业。写入状态与内容确认、完成状态独立，未写入不等同于待确认。缺少时间的事项在待安排中可达，过期也不代表已完成。

教务考试为只读项，显示官方时间／星期、考场和座位，点击复用只读详情；不进入完成、确认、编辑、删除或写入操作。原生与轻量Web共用`ScheduleListing`，先按相同日期、关键词、状态过滤，再与本地日程全局排序和每页24项分页，批量选择ID仅含本地项。考试未知时间保留原文并列入待安排，已结束列入历史；不满足待办范围，日历状态仅匹配全部与未写入，不冒充待确认。系统日程来源继续仅显示原系统活动。

日程读取考试缓存，不额外联网或触发学校同步；尚无缓存时考试筛选提供进入考试安排的入口，Web提示在手机刷新。完整缓存刷新会使原生快照失效；停用、退出或更换账号不显示旧考试，缓存损坏提示刷新且本地日程仍可使用。不复制考试为本地候选，不自动写入系统日历。

`ScheduleFilterState` 保存独立筛选草稿，日期、类型、待办、日历状态和来源共同生效；重置及编辑先改草稿，应用时提交，取消不影响列表。日期导航两端步进，中间选日期；清除筛选通过布局动画还原空间。

`ScheduleQuery` 在 SQLite 中执行本地日程的参数化筛选，`ScheduleListing`合并只读教务考试后稳定排序、计数与分页，每页24项；收件由`InboxQuery`每页加载12条。本地字段按所需分页前缀读取，全选只查询匹配的可编辑ID，保留跨页选择。两页底部分页统一复用持久DateIntervalBar，紧随结果、12dp上距，单页GONE无占位；箭头、左右滑动及点击页码选页共用边界，搜索／筛选后重算页数。结果重建不使分页条脱离，手势优先于主页切页。筛选变化归首页，详情返回保留筛选、页码与滚动；新作业定位按合并后的真实页码计算。

收件搜索对查询和原文、链接正文、候选标题及描述做 NFKC 与大小写规范化，按空白拆分关键词。每个词可在任一字段命中，全部词都命中才保留该收件；词序和中间文字不限，单个词不能跨字段拼接。例如「数学 作业」可分别命中原文中的课程名与候选标题中的作业。全半角等价，`%`、`_` 和反斜杠仍按普通文字搜索。空查询返回全部符合筛选的收件，排序、分页和跨页全选保持原规则。

收件与日程的待确认／待安排支持批量写入满足条件的内容。缺少字段或写入失败的项保留，结果反映逐项实际状态；系统来源只读，不进入本地批量删除和写入。

普通收件箱详情保留原文与附件，以及活动、待办和作业编辑；学校托管作业隐藏原文、附件和重新解析整组区域，数据仍保留。详情不再显示独立记录卡片或提供记录编辑／转换入口。历史独立记录数据保留在存储中，不主动清除。

## 系统日历关联

浙大作业若已明确启用新作业AI排程，生成的个人执行时段按普通个人安排显示并更新原日历关联；官方截止继续单独保存，未获授权或无合适建议时仍按截止时间点显示。自动排程不为同一作业新增第二个候选。

去重发布可以让多条本地事项关联同一系统事件。编辑其中一项的内容、备注、提醒或重复规则时，为该项建立独立事件并更新关联，其它事项仍使用原事件。删除或撤销关联时，仅在没有其它候选或永久合并记录引用时删除系统事件。

原生、网页、学校更新与同步删除共用 `LinkedCalendarEvents`。本次新建事件在最外层 SQLite 提交成功后保留；提交失败只清理本次新建项，已存在或复用的事件不参与该补偿。系统日历与本地 SQLite 分属两个存储，独占事件的原地更新及多项删除仍按顺序执行。

普通收件的「重新解析」无需先手工删除系统日程。原生与已配对网页共用 `CaptureReparser`：确认后先校验输入、AI配置、状态与日历权限，网页另校验数据版本；再清理本收件独占的旧系统事件，替换旧候选并提交排队状态，最后启动解析。其他候选或永久合并记录仍引用的事件保留；原文、附件与历次解析审计保留。取消确认不清理数据。学校托管收件继续禁止重新解析。

原生与网页重新解析确认正文统一为「这将替换已有日程」，不叠加清理流程与数据保留的解释。

清理失败不启动新解析，本地旧候选保留；跨存储多项删除中已经移除的系统事件无法回滚，提示后可直接重试，已不存在的事件视为清理完成。清理已提交但系统拒绝排队时，收件标为失败并提示重新解析，避免永久停在排队状态；不会恢复已清理的旧日程。

## 页面更新与详情

主导航最多保留三个页面，首次访问按需创建。异步结果绑定所属页面和数据窗口，旧结果不得更新新筛选。返回、轮询和局部状态变化保留未变卡片、输入与滚动位置；卡片移除后以布局位移补齐，不重新构建整页。

详情按需创建当前及相邻编辑页，访问过的表单保留草稿。滚动恢复回调绑定实际 owner 与页宽，不引用可能已切换的全局页面字段。具体编辑和来源边界见[折姜星辰](../zju/zju-services.md)、[日期时间选择](date-time-picker.md)及[交互基线](../../ui-interaction-baseline.md)。

任务详情标题行溢出菜单复用`HeaderActionGroup`与Lucide竖向三点图标，48dp点击区域；组按压1.10倍，点击打开菜单后正常回落，不用文字字符替代图标。候选入库或更新后的重复提示由应用级协调器统一处理，页面不另建扫描入口，见[重复日程合并](candidate-merge.md)。

## 已确认的业务布局

主页快捷操作按最近作业、系统日程、设置排列，共用 `HeaderActionGroup` 胶囊，关闭的功能移除入口及空位。「下一件事」在原有两行标题区域内显示标题与地点，不增加卡片高度或边距；无地点时标题仍可占两行。时间线卡片通过内部间距保持紧凑，外边距不变，作业截止附带作业标识。
主页及日历／周日程胶囊内各按钮复用公共填充按压高光；系统日程开关不使用独立圆形高光，启用状态只改变图标颜色。保留整组放大、取消与反向操作，以及开关权限和来源语义。

主页待办标题行在「全部待办」与右侧折叠箭头之间提供作业刷新图标，两者共用操作组。刷新只请求作业，进行中禁用重复点击并更新无障碍状态；结束后恢复按钮并局部刷新相关内容。未启用或未配置来源时进入折姜星辰设置；原有全部待办与折叠操作保持可用。

主页右上角作业图标以红点提示新入库且未查看的未完成作业。有红点时点击进入作业筛选，使用与列表相同的排序和分页规则定位最新未查看项；将该行置于可见滚动区域中央，短暂以主题色边框与淡底突出。首尾行仅在这次定位路径补足必要滚动空间，不缩小字体或触控区域。实际展示后只清除该项的新标记，其他新项保留红点；没有红点时保持原最近作业入口。具体来源与通知的独立状态见[折姜星辰](../zju/zju-services.md)。

日程与收件箱的筛选、计数和首条记录只保留一份间隔，不增加解释行。日历的系统日程开关合入标题行操作胶囊；周图片导出仅在周视图占位，切换时连续收拢。日期操作复用 `DateIntervalBar`，横滑优先于工作区切页。视图选择栏底板与五个等宽选项一起铺满内容宽度，文字居中，不增加内部动画边距；保留原动效，极端甩动允许高光出屏。年历根据当前字号的双位日期宽度选择一列或两列月份。

日程与收件箱筛选标签统一保持 14sp，按完整文字宽度分配单元。可用宽度足够时维持原行高、全宽排布及选择栏动效；窄屏或大字体放不下时，同一位置显示当前筛选和 Lucide 向下箭头，点击打开公共 `UiDialogs.choiceDialog`，完整显示全部选项及待处理计数。取消不改筛选，选择后立即更新按钮、列表和无障碍名称，不增加说明行或动画占位。

筛选选择栏按压、拖动与回落期间高于相邻类型筛选按钮；键盘焦点提升当前操作分支。交互结束恢复原绘制层级，控件位置与点击范围保持不变，底部导航始终高于列表内容。

筛选、类型选择及详情操作弹层使用无独立边框／底色的菜单行，相邻选项以细线分隔，保留选中勾、计数与整行点击。任务详情的空开始／结束提示见[日期时间选择器](date-time-picker.md)。

详情卡片标题保留新建、完成／确认操作；重复与删除在卡片末尾同行，状态操作使用小圆形图标。活动确认可撤销，仅未来或进行中显示；过期移除操作及空位。待办完成与恢复保持对应含义。类型栏使用标签右侧完整内容区域；来源网站双按钮位于卡片末尾。尺寸及对齐遵循公共 UI 规范。

## 日期、来源与周图片

普通事项使用本地日期边界，全天使用 UTC 日期边界，查询按区间相交包含跨日内容。日期相同用稳定 ID 排序，空日期保留且排序稳定；关键词中的 SQL 通配符按普通文字搜索。

来源过滤贯穿所有读取入口，关联的系统副本先按统一规则排除。来源页可看全部或按周，每次 50 条；全部模式的系统重复系列仅列一次，周模式列实例。空来源隐藏，查看不改变启用状态。详见[系统日历与来源](../calendar/system-calendar-home.md)。

周视图支持边缘继续外拖切周及双指缩放，两者避免手势冲突。保存 PNG 导出完整七天，不依赖可见滚动位置；可选附带日程索引。Android 10 及以上保存到公共 `Download/Chrona`，保存成功后自动打开系统分享面板；Android 8–9 使用系统文件保存器，默认定位下载文件夹，写入成功后同样分享。取消分享保留图片。生成与保存放在后台，取消清理临时图，读取失败、截断或内存超限时明确提示。
