# 日期时间选择器

## 起止时间联动

任务详情中，空的开始字段显示「欸~这好像还没有时间」，空的结束字段显示「遥遥路途，没有终点~」；切换类型、全天和恢复草稿保留这两条提示。提示仅在字段无值时显示，不写入时间数据；字段仍可点击打开日期时间选择器，并保留开始／结束的无障碍名称。

已填的开始、结束与截止值按可用宽度自然换行，表单行随文字增高；窄屏和大字体保留完整日期与钟点，不缩小字号、横向隐藏或省略内容。换行只影响显示，保存值和选择器输入保持原格式。

任务详情设置非全天开始时间时，若已填写的结束时间不晚于新开始时间，结束自动改为开始后 5 分钟。无结束时间的待办仍留空，全天日程保持日期边界语义。

作业个人执行时间可清空；清空开始同时清除结束，清空结束保留开始。结束为空时选择器默认定位到开始，确认前不写回字段；平台同步的截止仍由来源管理。

## 滚轮选择

- 用 GlassDateTimePickerView 自绘日期（年/月/日）与时间（时/分）滚轮；正文、选中强调和透明选中带使用 UiStyle 当前主题色，没有原生灰色时钟盘。
- 外层没有 ScrollView；滚轮触摸时禁止父级拦截，处理拖动、短距离惯性和居中吸附。分段切换或确认前完成吸附，避免读取尚未落定的数值。
- 按可见窗口高度与实测标题/按钮高度限制滚轮高度，包含字体缩放；绘制范围裁切在控件内。取消/外部点击不提交，确定后一次更新原字段。
- DateTimeSelection 只维护局部选择；月份、闰年变更时夹紧无效日期，小时/分钟循环，年份限制1–9999。保留默认时间来源规则。
- 无障碍可读取当前值、点按切换调整列、前后滚动增减当前列。

验证：DateTimeSelectionCheck 覆盖闰年、短月、24小时轮转、年份边界和原值不变。`DetailRepeatUiCheck` 的 `values` 范围在正常浅色与 320dp／字体 1.45／深色检查完整时间行、无省略、实际点按打开选择器和取消；实际执行与构建记录见[验证记录](../../validation-history.md)。
