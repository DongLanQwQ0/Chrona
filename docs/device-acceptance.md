## 判定与未覆盖项

每项结果填写“通过 / 失败 / 阻塞”，附实际版本、设备、步骤差异与截图或日志位置；失败记录复现条件和影响，阻塞说明原因。暂未执行保留原状态。涉及系统日历、Keystore、真实生命周期、安装器与桌面调度的行为必须由设备证据确认。启动耗时另按 [启动测量说明](motion-startup.md) 验收。

离线入口见 [发布与验证说明](github-releases.md)。当前清单是手工验收协议，尚无覆盖以上全部操作的设备端自动化；模型替身与桌面 SQLite 检查只能支持各自的逻辑结论。
