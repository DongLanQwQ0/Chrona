# 使用指南

[返回项目首页](../README.md)

拾时的基本用法是：记录内容，等待解析，核对草稿，再确认写入系统日历。应用内「设置 → 使用引导」提供六步教程和可复制的练习示例。

## 下载与安装

前往 [最新版本](https://github.com/DongLanQwQ0/Chrona/releases/latest)，在附件中下载 `Chrona-版本号.apk`，使用手机的系统安装器安装。支持 Android 8.0 及以上。

升级时直接覆盖安装，保留原应用。如果系统提示签名不一致，先停止安装并反馈问题，避免卸载后丢失本机记录。

## 配置 AI 服务

第一次使用，需要先准备 AI 服务的地址、模型名称和 API 密钥。

1. 打开「设置 → AI 服务」。
2. 填写服务商提供的地址和模型名称。常用模型预设可以帮助填写，密钥仍需自行提供。
3. 填入 API 密钥，点「保存设置」。
4. 返回主界面，尝试记录一条内容。

图片识别需要支持图片的模型。如果图片入口不可用，请检查所选模型的图片能力。服务使用与费用以你所选服务商的说明为准。

## 记录一件事

点主界面的 **+**，进入「记录一件事」。

- **文字**：直接输入，尽量写明事项、日期、时间、地点和提醒要求。
- **剪贴板**：点标题旁的剪贴板图标，追加已复制的文字。
- **图片**：点图片图标，选择截图或照片，也可以一次添加多张。
- **普通文件**：点文件图标，为记录附上文件。普通文件只提供名称等信息，文件正文不会交给 AI 解析。
- **系统分享**：在其他应用中选中内容或图片，通过分享菜单选择拾时。
- **链接**：把链接放进记录，拾时会尝试读取网页正文；需要登录或只靠网页脚本显示的内容可能无法读取。

检查内容后，点右上角 **✓** 保存。记录会进入收件箱并自动解析。

可以先试试：

> 明天下午 3 点到 4 点，在图书馆学习，提前 10 分钟提醒我。

## 查看与审核结果

「收件箱」保存原始记录和处理进度。可以按「待确认」「处理中」「失败」「已写入」筛选，也可以搜索原文。

1. 点击记录进入详情。
2. 核对标题、类型、开始与结束时间、地点、备注和提醒。
3. 点日期或时间字段修改时间；全天事项可以启用「全天」。
4. 点备注展开编辑。「提醒」中的数字表示提前多少分钟，留空表示不提醒。
5. 如果一条记录生成了多项日程，在日程区域左右滑动，逐项核对。

时间不明确时，先补全信息再确认。尚未写入日历的记录，可以修改原始内容、调整图片并重新解析。

## 确认与提醒

在详情中点右上角 **✓**，确认并保存当前日程。有多项日程时，需要分别确认；应用会提示还有多少项待确认。

确认成功的日程会写入拾时的专属系统日历。请允许日历权限，并在系统日历中开启通知和提醒。

**拾时的通知告诉你解析进度与结果；具体日程的提醒由系统日历发出。**

## 日常查看与修改

底部 Dock 的三个按钮依次是「首页」「日程」「收件箱」。可以直接点按钮，也可以在 Dock 上左右滑动，或长按后拖动高光；松手时高光落在哪个按钮，就打开对应页面。移出 Dock 后松手可取消。页面主体也支持左右滑动切页，高光会随页面平滑移动，取消滑动时回到原按钮；页面内的筛选条和日程卡片保留自己的横滑操作。

- **首页**：查看近期时间线和下一件事。
- **日程**：浏览识别出的事项，搜索关键词，按类型、日期范围或写入状态筛选。
- **修改**：点日程进入对应的一项，修改后点 **✓** 更新。
- **删除**：删除已写入的日程时，对应系统日历条目也会删除；删除整条记录会同时删除其全部日程。
- **小组件**：在手机桌面的添加小组件入口中找到拾时，选择合适的样式。不同桌面的操作位置可能不同。
- **外观**：在「设置 → 外观与配色」调整浅色、深色、主题色和背景。
- **更新**：每天首次打开首页后会在后台检查新版，无需等待；发现新版时会提示，同一版本只提示一次。在「设置 → 检查更新」可随时重试、查看说明并下载 APK，也可关闭自动检查。

## 备份与数据

在「设置 → 备份与恢复」导出完整备份，可以保存记录、日程、图片、普通附件和设置。换手机或进行重要操作前，建议先备份并妥善保存备份文件。

API 密钥默认不包含在备份中；如果主动勾选了包含密钥，请勿公开或转发该备份。

记录保存在本机，用于解析的文字和图片会发送给你配置的 AI 服务。密钥在本机加密保存。含链接的记录还会尝试访问对应网页。

## 常见问题

### 一直没有解析结果，或显示失败

检查网络、服务地址、模型名称和密钥，然后在记录详情中重试。部分手机会限制后台运行；等待结果时可以保持应用在前台，并检查手机的后台运行设置。

### 日程识别不准确

先在详情中修改草稿，再确认。记录时尽量给出明确的日期、时间和事项；网页内容读不到时，可以补充正文或截图。

### 图片入口不可用

确认模型支持图片。如果之前的图片请求被拒绝，可以在 AI 服务设置中检查图片支持状态，必要时重新允许图片输入。

### 为什么确认一项后，还有待确认数量？

一条记录可能包含多个日程，确认只针对当前一项。继续检查并确认剩下的日程即可。

### 日程已经确认，但没有提醒

检查这项日程的提醒是否留空，再检查日历权限、系统日历通知与提醒开关，以及手机的通知或省电限制。

### 想重新看一遍教程

打开「设置 → 使用引导」，随时可以从头浏览六步教程。

仍未解决？请通过 [GitHub Issues](https://github.com/DongLanQwQ0/Chrona/issues) 反馈，并提供版本、复现步骤和必要截图；隐藏 API 密钥和个人信息。
