# 使用指南

## 活动、待办与作业

- **活动**：填写开始、结束时间，可添加地点与提前提醒；进行时显示活动进度。
- **待办**：可不设时间，也可填写截止时间和执行时段。点卡片或普通通知上的勾标记完成，在历史中可恢复。未完成的逾期待办仍留在待处理。首页待办摘要提供今日截止、已逾期、待安排入口；下一件事只展示执行安排。点首页“待办”标题折叠或展开重点条目，分类计数保持可见，状态会记住。日程页顶部筛选栏显示当前范围，可清除或打开筛选面板。完成后停用关联的系统日历提醒，恢复时只恢复未来提醒。缺少日历权限时先保留本地状态并提示，授予权限后在刷新时重试。
- **作业**：课程布置的习题、报告和项目，支持截止时间、执行安排及完成状态。

收件箱保留输入原文、图片和附件；纯信息不额外生成记录卡片，可在原文中查看和修改。

## 提醒与稍后提醒

在「设置 → 通知与提醒」查看应用权限和具体提醒频道；关闭频道时可直接前往对应系统设置。待办选择“5 分钟后提醒”会在届时重新出现并保留 3 分钟。活动的“稍后提醒”最迟在结束前 30 秒返回，最后 30 秒不再提供该操作。

## 电脑浏览器局域网访问

1. 手机与电脑连接同一个可信 Wi-Fi 或以太网局域网。
2. 手机「设置 → 局域网访问」开启访问，按提示允许通知与附近设备权限。
3. 在电脑浏览器输入手机显示的 `http://…:8765` 地址，再输入六位临时配对码（保留前导零）。
4. 浏览器可管理活动、待办、作业与收件箱，批量写入日历、上传图片和文件、调用手机 AI、管理课表来源、导入/下载 ICS，并查看日／周／月／年日历、导出周图片。修改直接保存到手机；日历操作使用手机已有授权。

手机显示自动配对二维码，可信设备扫码即可连接，无需手输；也可用上方普通地址和六位码手动配对。二维码包含临时配对凭据，请仅向可信设备展示；过期时在手机重新配对。

网页随 APK 提供，无需安装电脑客户端。配对码 10 分钟后过期，可点重新配对；浏览器会话只在本次开启期间有效；关闭服务、重新配对、手机应用进程退出或网络地址变化后会撤销连接。浏览器会话最长 12 小时，请重新配对继续访问。手机通知中可随时关闭服务；重启手机后需手动开启。

HTTP 连接用于可信局域网。请勿将端口转发到公网。无法访问时检查手机的服务状态、访问地址、通知/附近设备权限、路由器设备隔离及电脑防火墙。服务开启状态表示已成功监听手机地址，实际电脑连接仍取决于局域网和手机后台限制。

AI 账号、WebDAV 密码、权限授权、系统通知与小组件设置在手机端管理；浏览器使用手机的配置与运行状态。手机后台发起的 AI 处理遵循系统任务调度，可能等待网络或后台执行窗口。正在处理的记录不能修改；已有日历关联的记录须在手机取消关联后重新解析。

网页弹窗提交期间会暂停重复操作；操作失败时在弹窗内显示原因，保留输入供重试。

## 多台 Android 设备与坚果云同步

各手机在「设置 → 跨设备同步」填写同一个坚果云账号和应用密码，地址使用 `https://dav.jianguoyun.com/dav/`，先点“测试连接”，连接成功后点“保存设置”，再点“立即同步”。测试连接仅验证当前输入；保存设置后才会更新账号配置。已有账号的应用密码留空时沿用已保存密码。同步日程、课表、原文和附件；外观、AI 密钥、提醒偏好、系统日历关联各自保存在本机。可选择自动同步，Android 后台执行时间受系统调度影响。已开启自动同步时，浏览器修改会触发手机同步。

出现冲突时，在手机或已配对网页的同步设置中检查版本并选择保留内容。云端更新涉及已写入系统日历的记录时，需明确确认移除旧事件后应用；新版本需再次手动写入系统日历。手机恢复完整备份会关闭自动同步、保留已有实体身份，与云端不同的版本可能待确认，请先整理数据。浏览器显示所连接手机的内容和操作结果。使用日程合并前，所有同步设备须升级到 0.14.4 或更新版本。

处理结束后待确认列表自动刷新。同步忙碌时请等待完成后重试；处理失败的记录仍可再次确认。确认完成后点击“立即同步”上传选择。

## 下载与安装

前往 [最新版本](https://github.com/DongLanQwQ0/Chrona/releases/latest)，在附件中下载 `Chrona-版本号.apk`，使用手机的系统安装器安装。支持 Android 8.0 及以上。

升级时直接覆盖安装，保留原应用。如果系统提示签名不一致，先停止安装并反馈问题，避免卸载后丢失本机记录。

## 导入课程表

点击首页「今天的安排」进入课表，选择「导入 ICS」，选取学校导出的 UTF-8 日历文件。检查学年、秋冬／春夏或单学期类型及日期范围，点击日期可调整。界面会列出各学期课程数量，并提示将替换的同学期；其他学期保留，读取或保存失败保留原内容。

顶部先选学年秋冬／春夏，再选择具体学期。首次进入显示当前学期，假期选择最近的有课学期，之后记住选择。统计为该学期课程门数和实际安排总时长，包含下方特殊安排。

常规课程按周一至周日及文件内实际时间展示；相同课程、地点、星期与时段合并，长课保持连续色块。冲突课程并排显示，拥挤时可横向滑动。零散时段集中显示在「特殊安排」，不会自动认定为调课或考试；规律性的周末课程正常进入网格。

点击色块或特殊安排查看地点、备注与具体日期。在详情中可选择「移至特殊安排」或「放入课表」；「管理」提供恢复自动分类和删除此学期。此功能无需配置 AI，数据仅保存在本机，完整备份包含多学期课表、选择状态及分类调整。

导入课程在课表页管理；网页首页与日历汇总已启用的课表来源。在日程来源设置中可启用来源、选择主来源并分页查看全部内容。导入与写入系统日历是独立操作。

首页或「设置 → 外观与显示 → 包含系统其他日程」控制首页、系统来源日程列表和网页。小组件在「设置 → 桌面小组件 → 包含系统其他日程」独立设置，提前提醒在「设置 → 日程常驻提醒」独立设置。开启须授予手机读取权限；不按标题或时间去重系统事件。

需要整理拾时内部重复日程时，进入「设置 → 合并完全相同日程」，先扫描预览，再确认。所有业务字段、提醒/确认状态及关联事件必须完全一致；来源记录和附件保留，合并结果详情可查看来源。不删除系统事件，合并标记会同步给其他手机。

## 配置 AI 服务

第一次使用，需要先准备 AI 服务的地址、模型名称和 API 密钥。

1. 打开「设置 → AI 服务」。
2. 填写服务商提供的地址和模型名称。常用模型预设可以帮助填写，密钥仍需自行提供。
3. 填入 API 密钥，点「保存设置」。
4. 返回主界面，尝试记录一条内容。

图片识别需要支持图片的模型。如果图片入口不可用，请检查所选模型的图片能力。服务使用与费用以你所选服务商的说明为准。

## 记录一件事

点主界面的 **+**，进入「记录一件事」。

- **文字**：直接输入，尽量写明事项、日期、时间、地点和提醒要求。
- **剪贴板**：点标题旁的剪贴板图标，追加已复制的文字。
- **图片**：点图片图标，选择截图或照片，也可以一次添加多张。
- **普通文件**：点文件图标，为记录附上文件。普通文件只提供名称等信息，文件正文不会交给 AI 解析。
- **系统分享**：在其他应用中选中内容或图片，通过分享菜单选择拾时。
- **链接**：把链接放进记录，拾时会尝试读取网页正文；需要登录或只靠网页脚本显示的内容可能无法读取。

检查内容后，点右上角 **✓** 保存。记录会进入收件箱并自动解析。

可以先试试：

> 明天下午 3 点到 4 点，在图书馆学习，提前 10 分钟提醒我。

## 查看与审核结果

「收件箱」保存原始记录和处理进度。可以按「待确认」「处理中」「失败」「已写入」筛选，也可以搜索原文。

1. 点击记录进入详情。
2. 核对标题、类型、开始与结束时间、地点、备注和提醒。
3. 点日期或时间字段修改时间；全天事项可以启用「全天」。
4. 点备注展开编辑。「提醒」中的数字表示提前多少分钟，留空表示不提醒。
5. 如果一条记录生成了多项日程，在日程区域左右滑动，逐项核对。

时间完全明确且模型肯定时，日程自动确认并写入，结果通知列出标题、时间、地点、提醒及备注。模糊时间由模型直接选择一个合理建议，标为高存疑待确认；你可以修改或接受建议。缺少日历权限或写入失败时保留草稿，通知说明原因。尚未写入日历的记录，可以修改原始内容、调整图片并重新解析。

详情会标出缺少的时间、由默认时长补全的结束，以及已写入日程的未保存修改。“明天”等相对时间始终按记录创建时刻、解析设备当前时区解释，排队跨日和重新解析保持同一参照；原文与编辑弹窗可查看参照时间。修改旧原文也沿用该参照，需要以当前时刻重新表达时请新建记录。

## 确认与提醒

对仍待确认的项，在详情中点右上角 **✓** 确认并保存。明确项已经自动写入；混合记录只需要处理剩余草稿。

返回列表后，待确认角标与收件箱总角标一起更新。角标统计收件记录数；同一记录还有其他待确认项时会保留，全部确认后移除。

确认成功的日程会写入拾时的专属系统日历。请允许日历权限，并在系统日历中开启通知和提醒。

在「设置 → 通知与提醒」开启开始前 30 分钟提醒。活动持续至结束，非活动日程在到点后保留 3 分钟；可查看详情、稍后提醒或隐藏本次。明确且无需确认的非全天日程参与，系统日历原有提醒仍按每项设置执行。

允许通知后，再点「准时提醒」授予系统的精确闹钟权限；未允许时系统可能延迟触发。重启、时间/时区变化或日程修改会重新计算卡片。原子卡片显示期间使用前台服务维持更新；手机后台耗电策略仍可能限制刷新。

没有收到提醒时，打开「设置 → 通知与提醒 → 提醒诊断」查看应用、提醒频道和日历状态，并进入系统日历核对该事项的提醒。

## 日常查看与修改

底部 Dock 的三个按钮依次是「首页」「日程」「收件箱」。可以直接点按钮，也可以在 Dock 上左右滑动，或长按后拖动高光；松手时提前计算阻尼后的落点并开始切页，高光同时继续运动。移出 Dock 后松手同样有效。页面主体也支持左右滑动切页，高光会随页面平滑移动，取消滑动时回到原按钮；页面内的筛选条和日程卡片保留自己的横滑操作。

- **首页**：查看近期时间线、下一件事及待办摘要。作业有执行安排时按开始时间展示并注明截止；只有截止时间时按截止时间显示「作业截止」，无日期的作业保留在待安排。标题右侧的日历图标切换是否包含系统其他日程。
- **作业时间**：个人执行时间选择器可清空；清空开始会一并清除结束，清空结束保留开始。未填结束时，选择器默认定位到开始时间，确认前不会改动字段。课程平台同步的截止时间保持只读。
- **未写入**：日程筛选的「日历状态 → 未写入」列出尚未关联系统日历的活动、待办和作业，可多选写入完整内容。「待确认」用于核对识别结果，不等同于未写入；失败或缺少必要信息的内容保留供修正重试。
- **连堂课**：同一天、同来源、课程名称与教室相同、课间不超过30分钟的相邻课程段合成一张卡片，保留完整起止与两段备注；普通预约、缺课一节、午休、不同课程或不同教室不合并，原始课表不改写。
- **日程**：浏览识别出的事项，搜索关键词，按类型、日期范围或写入状态筛选。
- **日历**：点「收件箱」标题下划线入口，切换年/月/周/日/日程视图；点日期标题选日期，点「今天」定位。“包含系统日程”开关独立保存，只作用于此页面。周视图可任意方向拖动；点击卡片查看详情，全天事项超过三项可点数量展开。刷新和详情返回保留位置。
- **日历手势**：在日历内容区向左滑动查看下一段日期，向右查看上一段。周视图先横向滚动，到边缘后继续向外拖动即可切周，抵达边缘本身不会切周；双指捏合可缩放至完整一周或放大细看，缩放期间不会触发切周。
- **导出周图片**：在周视图点标题栏导出图标，选择是否“附带日程索引”，再保存图片。默认只保存完整周表，开关会记住选择，导出不受当前滚动位置影响。
- **月内选日**：点同月的另一日期，只更新选中高光与当天日程，整个月历和滚动容器保留。选择同一天不会重复刷新。
- **来源颜色**：系统日程采用所属日历颜色与主题色的混合，显示在来源色点和周/日/全天卡片上；缺少日历颜色时使用主题色。标题栏可直接搜索日程。
- **Dock 手势**：在主导航或日历视图条水平拖动，手指移出栏后松开也有效。松手时预先计算自由减速与边缘回弹后的落点，立即切换对应页面；高光同时继续运动。多指或系统取消不会切换，网页 Dock 同样支持。
- **Dock 动效**：半透明高光与背景混合，选中按钮显示主题色。高光与整栏放大的过程放慢至此前的 1.5 倍，松手后的普通滑行阻力增加 50%。甩出时内端保持半个标准宽度的锚点，外端越接近标准高光宽度 75% 的最大伸出距离，延伸阻力越强，随后回弹。
- **月视图**：本月日期清晰、相邻月份日期减弱；底部的小号数字表示日程数，色点按 1–2、3–5、6 项以上分级。今天有描边，选中日有高光背景。顶部视图条支持滑动高光，系统关闭动画后即时切换。
- **排序**：「未来、未定、以前、全部」分别记住方向，点击标题右侧箭头修改。未来默认最早在前，以前默认最近在前。
- **筛选状态**：条件生效时，列表上方显示当前日期、类型、状态、来源或关键词；点「重置」清除这些条件，保留当前时间标签。
- **修改**：点日程进入对应的一项，修改后点 **✓** 更新。
- **删除**：删除已写入的日程时，对应系统日历条目也会删除；删除整条记录会同时删除其全部日程。
- **小组件**：在手机桌面的添加小组件入口中找到拾时，选择合适的样式。不同桌面的操作位置可能不同。
- **弹幕**：在「设置 → 桌面小组件 → 鼓励弹幕」独立开关；系统动画关闭时也会在小组件下次刷新隐藏。弹幕开关与明日预览时间随完整备份恢复。
- **外观**：在「设置 → 外观与配色」调整浅色、深色、主题色和背景。“背景图片”右侧开关可暂时关闭图片，再打开无需重选；下方“选择图片”与“恢复默认”并排显示。
- **动效**：滚动卡片、页面切换和详情展开采用有限过渡，快速反向操作会连续衔接。新增原生页内动效跟随系统动画开关，网页跟随系统/浏览器的“减少动态效果”；后台刷新不会重播入场。
- **自定义颜色**：点击主题配色中的“自定义颜色”，拖动色相、饱和度、明度滑杆或输入六位色值，点击“应用颜色”保存；取消会保留原配色。
- **更新**：每天首次打开首页后会在后台检查新版，无需等待；发现新版时会提示，同一版本只提示一次。在「设置 → 检查更新」可随时重试、查看说明并下载 APK，也可关闭自动检查。

## 备份与数据

设置页按「外观与显示、桌面小组件、日程常驻提醒、服务与数据、帮助与关于」分组。数量与时间直接显示在选项右侧，点整行修改。版本、GitHub 主页和作者 QQ 在「帮助与关于 → 关于拾时」浮窗内，QQ 可点击或长按复制。

在「设置 → 备份与恢复」导出完整备份，可以保存记录、日程、图片、普通附件和设置。换手机或进行重要操作前，建议先备份并妥善保存备份文件。

API 密钥默认不包含在备份中；如果主动勾选了包含密钥，请勿公开或转发该备份。

记录保存在本机，用于解析的文字和图片会发送给你配置的 AI 服务。密钥在本机加密保存。含链接的记录还会尝试访问对应网页。

## 常见问题

### 一直没有解析结果，或显示失败

检查网络、服务地址、模型名称和密钥，然后在记录详情中重试。部分手机会限制后台运行；等待结果时可以保持应用在前台，并检查手机的后台运行设置。

### 日程识别不准确

先在详情中修改草稿，再确认。记录时尽量给出明确的日期、时间和事项；网页内容读不到时，可以补充正文或截图。

### 图片入口不可用

确认模型支持图片。如果之前的图片请求被拒绝，可以在 AI 服务设置中检查图片支持状态，必要时重新允许图片输入。

### 为什么确认一项后，还有待确认数量？

一条记录可能包含多个日程，确认只针对当前一项。继续检查并确认剩下的日程即可。

### 日程已经确认，但没有提醒

检查这项日程的提醒是否留空，再检查日历权限、系统日历通知与提醒开关，以及手机的通知或省电限制。

### vivo 原子岛日程提醒

在「设置」开启开始前30分钟提醒；是否包含系统日程可单独选择。个人开发设备的原子岛需要完成一次本机配置，之后日常发送不需要连接电脑，详见 [vivo 原子岛设置](features/reminders/vivo-atomic-setup.md)。

### 想重新看一遍教程

打开「设置 → 使用引导」，随时可以从头浏览六步教程。
