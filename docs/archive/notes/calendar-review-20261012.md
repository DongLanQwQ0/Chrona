# 日历细节审查 · 0.14.8

审查完成后开始修改。范围为日历活动、快照读取、时间布局、Dock 复用与首页课表主体。

| 问题 | 证据与影响 | 修改方向 |
| --- | --- | --- |
| 过期读取排队、旧内容可操作 | load 每次向单线程提交；generation 仅丢弃返回结果。旧界面的日期点击仍使用旧月份闭包，当前 mode/date 已改变 | 取消旧任务和提供器查询；数据上下文改变时隔离旧内容输入 |
| 滚动位置丢失 | renderBody 每次新建 ScrollView；timeline 每次 post 初始定位 | 同一窗口刷新、搜索和详情返回恢复位置；保存旋转状态 |
| 连续切换画面跳变 | renderBody 先 finishBodyMotion，将未完成的入场强制置为 alpha=1/translation=0 | 中断时保留当前内容实际视觉位置；新动画只管理两层，身份保护回调 |
| 周定位和区间边界 | 默认横向位置为 0；first.plusDays(days).isBefore(today) 把排他结束日当作在范围内 | 初次聚焦选中日期列；严格处理排他区间 |
| 年/月计数开销 | 每个日期调用 onDay(entries)，最多 504 次扫描并创建列表 | 差分计数索引，按快照窗口一次计算，不扫描日程来画每个日期 |
| 时间状态滞后 | minuteTick 只重绘 nowLine；日程列表的“现在/已结束/分钟后”固定 | 原位更新标签与标题状态；跨午夜更新日期样式 |
| 大字体、选中语义不足 | 日期标题固定 22sp；计数由 Canvas dp 字号绘制；视图标签仅变色 | 标题单行自适应、计数用 sp 文本、日期行适配字体大小、选中态无障碍语义 |
| 短事件标题被裁切 | 最小 18dp 卡片仍上下 padding=7dp，12sp 标题可见区不足；午夜处还会越界 | 短事件精简单行、约束高度与上下边界 |
| 全天项撑满页面 | 全天列无数量限制，time ScrollView 为剩余权重高度 | 每天显示少量全天项，其余通过可滚动详情列表访问 |

课表主体和空课表占位的 elevation 均为 0，未发现去阴影回归。Dock 连续手指跟随和高光位置维护沿用原实现。

验证：新增真实日期计数/边界检查，定向执行生产读任务、视觉中断和滚动状态方法（Android 替身）；相关回归、构建、lint、原签名、发布下载与更新解析。Android 真机验证取决于是否有连接设备。
