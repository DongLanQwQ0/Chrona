# 液态玻璃 Dock 参照说明（调研稿）

来源：Apple Human Interface Guidelines *Tab bars*／*Materials*（Liquid Glass）、WWDC25 相关资料整理。本文件只记录“要模仿什么”，不含实现结论。

## 一、Apple 那边的实际行为

来自 HIG 原文的硬事实：

1. **浮在内容之上**：iOS 的 tab bar 浮在内容底部，条目不画自己的底板，而是“坐在一块 Liquid Glass 上”，底下内容透出来。
2. **两种材质**：regular 会模糊并调整背景亮度以保证文字可读，绝大多数系统组件用它；clear 几乎全透，只用于图片／视频这类视觉丰富背景之上，必要时补 35% 暗化层。
3. **最小化（minimize）**：带附属物（如 MiniPlayer）时，向下滚动可以把 tab bar 收起来，收成“当前所在的那一个 tab”，停在屏幕底部一侧；点任意 tab 或滚回顶部恢复。
4. **标签与角标**：图标下（或横屏时右侧）带单字标签；红点／数字角标只用于关键信息。
5. **不要禁用或隐藏 tab**：内容不可用时也要保留入口，说明原因。

WWHC25 对“可交互玻璃”的描述（非 HIG 原文，属公开资料整理）：玻璃会随触摸产生形变与高光响应，而不是一块静态半透明板；相邻玻璃元素靠近时可以融合成一体。

## 二、要模仿的 4 个动作

| 行为 | Apple 的表现 | 我们要对齐的点 |
| --- | --- | --- |
| 选中镜片 | 选中项坐在一块玻璃镜片上，切换时镜片在 tab 之间移动并轻微拉伸 | 现有 DockSpring 的位移与拖尾保留，但镜片要有“玻璃边缘”高光，而不是纯色胶囊 |
| 按压响应 | 按下的 tab 玻璃局部鼓起，同时整条轻微下沉／抬升 | 现在只有整条 1.1 倍与高光 1.5 倍，缺少被按那一项的局部响应 |
| 最小化 | 向下滚动收成当前 tab，点一下或回顶恢复 | 目前完全没有；可作为可选项，滚动超过阈值时收起 |
| 材质 | regular：模糊 + 亮度调整；边缘有折射感高光 | 现有亚克力已有模糊与描边，缺“边缘亮度带”和内外高光 |

## 三、明确不做的

- 不做真实光栅折射（Android 上代价高、易穿帮），用“边缘 1dp 亮带 + 内侧 1dp 暗影 + 顶部高光”近似。
- 弹簧已按 2026-10-31 授权改为 Apple 模型（response 0.38s／damping 0.93、惯性阻尼 5.5）；旧的临界阻尼参数不再适用。
- 不引入液态玻璃到内容层（卡片、列表），只用于 Dock 与浮动选择栏。

## 四、落地顺序（全部在模拟器验证）

1. **材质层**：给 `DockNavigationLayout` 的底板加边缘亮带与顶部高光（`UiSurfaces` 里新增一个 drawable 变体，不动现有亚克力）。
2. **镜片层**：高光从纯色胶囊改为“玻璃镜片”——同色但更低透明度 + 内描边 + 顶部亮带。
3. **按压局部响应**：被指的 tab 在现有 1.5 倍之外，追加 1.04 的局部鼓起与 1dp 下沉，与整条 1.1 倍叠加。
4. **最小化**：任意 section 向下滚动超过 160dp 时，Dock 收成当前 tab 的小胶囊，停靠左下；回顶或切换页面恢复。

## 五、验证方式

- 只用本机模拟器 `emulator-5580`（Android 16／1080×2376），不碰真机。
- 每一批改动在模拟器上截“静止／按住／拖动中／最小化”四张图，与 Apple 的公开截图逐项对照。
- 一次性打包，确认无误后再询问是否推到真机。
