# 首页系统日历

0.13.39：主页提供「包含系统其他日程」复选框，默认关闭，记住选择并随完整备份恢复。开启时单独请求读取日历权限。

- 在后台读取可见日历的 `CalendarContract.Instances`，展示今天起一个月内的日程实例，包含重复日程。
- 与应用日程合并排序后应用首页数量上限；「下一件事」最多 5 项。用所有候选的关联事件 ID 排除应用已写入日历的重复显示，同一重复事件的不同实例保留。
- 系统日程只读，点击打开系统日历详情，不复制成收件，不参与 AI 请求。备份保存开关，系统其他日程仍以当前设备日历为准。
- 首页前台每 5 秒检查变化，返回首页重新读取；查询可取消，结果不变时不重绘，更新时保留滚动位置。UTC 全天日期转换为当地日历日期，不用固定 24 小时推算夏令时日期。
- 查询范围前后各扩展一天以覆盖全天日程的时区边界，最多读取 1000 个实例，避免异常日历数据拖慢首页。

验证：纯 Java 检查覆盖关联事件去重、重复实例保留、同名事件保留、缓存变化和夏令时全天日期；Gradle 编译与 lint。未执行设备日历权限、厂商 Provider 和跳转 UI 验收。
