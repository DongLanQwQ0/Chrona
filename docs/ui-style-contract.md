# Chrona 原生 UI 强制约束

本规范适用于新增页面、弹窗以及本次修改涉及的现有区域。实现前必须阅读本文件、`docs/development.md` 的原生设置页布局规范及目标公共组件。出现冲突时，以用户最新明确要求为准，并同步修订本规范。

## 0. 严格执行需求，禁止自行增加限制

- 未经用户明确要求，不得自行增加可见交互、视觉限制、隐藏条件或更改功能含义；不得以个人审美、常见做法、避免裁切或防御性设计为由改变用户指定的行为。
- 修复实现问题应恢复用户要求的效果。高光需要溢出时，修正绘制层级和父容器；禁止擅自改为框内限幅、向内挪动、挤压形状或缩小动画。
- 发现实质歧义先核对原始要求；无法明确时先询问。额外改进先提出、得到同意后实施，不得夹带在修复中。规范不得反过来固化未经授权的设计取舍。

## 1. 公共组件是唯一入口

| 对象 | 必须使用 | 禁止 |
| --- | --- | --- |
| 二级设置与查看页 | `SettingsPageLayout.content/header/show` | 自写安全区、贴屏容器、重复叠加 inset |
| 内容卡片 | `UiStyle.card`，`RADIUS_CARD=22dp` | 用超长胶囊承载多行内容、给整段 TextView 直接套按钮背景 |
| 浮层 | `UiStyle.dialogPanel` + `showFloatingDialog` | `AlertDialog.Builder`、平台默认灰色矩形、只给子控件套圆角 |
| 长浮层内容 | `UiStyle.dialogBody` | 无界文本撑破屏幕、操作按钮随长正文滚走 |
| 操作、输入与开关 | `UiStyle.button/input/toggle` | 硬编码品牌色、原生默认按钮外观 |
| 选择栏 | `DockNavigationLayout` 与 `motionHost` | 为修裁切缩小高光、强制文字换行、逐页另造高光实现 |

浮层最外层使用公共圆角、亚克力、主题配色、背景模糊和开合动画。关闭按钮使用公共按钮样式。不要仅调用 `.show()` 后期待系统弹窗自动适配主题。

## 2. 尺寸必须使用 dp / sp

- 页面左右 **20dp**；公共标题栏之后至少 **16dp**，由标题栏自身提供。内容卡片不能抵消页面留白。
- 卡片正文左右 **16dp**、上下 **12dp**；相邻记录间 **8dp**。禁止 `setPadding(16,16,16,16)` 一类裸像素值。
- 浮层内距 **20dp**，标题与正文 **12dp**；字段组间 **12–16dp**，按钮之间 **8dp**。
- 详情表单统一 **54dp 最小行高**，正常字号下类型、标题、时间、地点等单行字段视觉同高。多行备注可自然增高；禁止选择栏单独撑出大块上下留白。
- 图标操作使用 **48dp** 触控区、**24dp** 图标。装饰箭头 **18dp**，不抢占独立点击焦点。
- 以上为正常字号基线。大字体按文字自然增高，禁止固定高度裁字或把必要说明缩成小字。

## 3. 内容层级必须能一眼区分

- 页面标题沿用公共 **24sp**，浮层标题 **21sp**。
- 卡片标题 **16sp**、主题正文色；次要状态与时间 **13sp**、`muted`。标题与元信息之间 **4dp**。
- 列表标题最多两行、省略尾部；完整内容必须能在详情中查看。不要把标题、状态与时间拼成同字号的文字墙。
- 作业记录按日期分组，卡片只放标题、变更类型与时刻；点击整张卡片查看变更。
- 新增记录直接展示截止与提交状态，不重复展示“未设置 → 新标题”。更新记录按字段展示原值与新值，不在单行挤入两个长值。
- 业务未知必须明确显示未知。缺失提交状态不能显示为未提交。
- 图标使用现有 Lucide 资源；状态、可用性同时提供无障碍描述，不能只靠颜色。

## 4. 选择栏紧凑但不裁动画

- 筛选浮层的选择栏必须**填满内容宽度，与应用按钮左右对齐**，使用 `fullWidthMotionHost()`，禁止为了动画包络把整条轨道缩成居中的窄条。高光允许自然溢出轨道并覆盖相邻空白，保留放大与回弹；禁止将其限制在框内、向内挪动或压缩跨度。
- 同组选择栏的**外框同宽、左右对齐**；内部选项按真实字宽分配，禁止因等宽让“今日截止”等文字折行。
- 密集表单使用 `motionHost(true)`，允许高光跨相邻行的空白区域绘制；中间父容器关闭裁切。保留最终滚动视口边界，首尾用真实安全空间容纳动画。
- 不把完整竖向放大包络转成每个字段永久占位。行高由表单内容决定，动画由绘制层承担。
- 保留公共长按放大、短按脉冲、快速滑动阻力与回弹。高光位置、宽度和跟随时的高度均连续过渡，禁止闪切。
- Dock 动效以用户提供的 `Screenrecording_20261017_140740.mp4` 为参考：按下即预览目标但不提前提交导航，前沿先走、尾部追随，反向从当前两端位置衔接。额外拉伸采用有界的前后沿距离，禁止与按压比例连续相乘而形成长条。物理圆角按实际高光高度计算，反向抵消节点缩放，文字和图标不参与高光拉伸；颜色按覆盖程度连续过渡，可同时照亮跨过的两个选项。
- 浮动轨道可向触点轻微偏移，松手或取消后回中；全宽表单轨道不作水平偏移。所有选择栏在手指按下当帧即以1.5倍为目标开始放大，不等待长按或拖动；松手从当前尺寸连续收回，短按脉冲更小，收回响应保留放大的1.5倍时长。
- 底部「＋」仅首页显示，日程和收件箱隐藏。使用公共非线性曲线，按钮缩放、渐隐并模糊退出；Dock 以整体平移到中央为主，仅适度增加宽度，禁止固定左端把右端单独拉长。返回首页反向恢复；按真实宽度重排导航，禁止横向缩放文字。半途反向或取消从当前帧衔接，不重建页面、不改变内容高度；隐藏及切换中的按钮停用点击和无障碍焦点。宽屏只隐藏快捷操作，不扩缩侧栏。
- 选择日程或收件箱后，主页Dock居中时间为原来的0.5倍；「＋」的模糊退出时长保持不变，不得因加快整栏位移而同时加快按钮退出。
- 主页底部 Dock 自动选中移动保持1倍，详情、筛选等其余选择栏的自动选中移动为0.5倍。手指实际拖动的前沿和尾部使用实时跟随，不继承自动选中的慢速；仍须连续动画，禁止闪切。不更改按压放大、松手缩小的节奏。
- 拖动时高度向 **95%** 平滑变化，到位后恢复；缩小动画时长为放大的 **1.5 倍**。页面不得另写不同参数。
- 正常放大溢出与惯性越界分开处理：松手速度不再统一减半，以同栏全跨度点击切换的峰值速度为上限，预测与实际积分使用相同限制；边缘回弹时间缩短至原来的2/3，保持阻尼比，禁止用高阻尼急停破坏跟手，禁止以框内限幅代替阻尼。按钮模糊使用透明边缘采样和透明绘制余量，禁止用CLAMP重复按钮描边产生十字亮点；绘制余量不得改变实际按钮位置和触控区域。「＋」退出至少460ms、缓入缓出，页面提交不得提前截断。
- 选择栏背景的 GPU 接缝由公共亚克力背景层处理。禁止给整条选择栏加软件位图层来遮盖接缝：文字与高光必须维持独立节点，长按放大的高光不得被静止外框裁掉。

## 5. 交互、主题和功能边界

- 列表行点击打开详情；行内开关只改变启停，两者不能相互触发。箭头与实际跳转一致。
- 主页标题右侧快捷操作按「最近作业、系统日程、设置」排列，使用48dp触控区域，按钮之间至少8dp真实间距；功能关闭时移除对应入口及其空位。禁止多个圆形按钮紧贴，禁止靠图标透明区域冒充布局间距。
- 活动确认是删除按钮左侧的小图标按钮。确认后切换图标与主题强调色，再点撤销；不占据单独一行。
- 待办完成／恢复与活动确认统一放在详情卡片标题行，顺序固定「新建 → 完成／确认 → 删除」。状态操作是 48dp 圆形触控区、24dp 图标，按钮间 8dp；禁止再添加整行完成按钮。作业网站入口在卡片末尾同一行，等宽双按钮、8dp 间距。
- 所有颜色来自 `UiStyle.colors`。背景可透明、模糊，文字保持清晰；不要通过降低整张卡片透明度表示次要文字。
- 主题切换、后台刷新、待办展开与折叠不重播整页入场。移动后的模糊背景采样必须跟随实际位置。
- 完成待办或确认活动后，按稳定业务标识局部协调列表：存活卡片保留原View、焦点和滚动位置，使用真实布局位移动画填补空位。首页轮询及日历回调不得紧接着重建整页或强制滚至顶部。
- 首页时间线通过内部上下留白与信息行间距保持紧凑，不改变卡片外边距，不压缩字号或48dp操作触控区。作业截止必须含「作业」文字标识与作业图标。
- 详情类型选择栏填满标签右侧可用内容宽度，复用 `fullWidthMotionHost()`，禁止用高光安全留白将轨道压成窄条。活动确认／撤销仅在未来或进行中显示；过期时使用 GONE，不保留空白按钮位。
- 未启用「折姜星辰」时，仅保留设置中的启用入口。日程来源、主来源选项、课程关联、查看页不展示浙大入口、文案和缓存内容。直接跳转也必须校验，保留原始数据及用户偏好。
- 来源内容页允许查看已关闭的普通来源，按可见日期窗口只读查询；查看不自动启用来源。
- 完全相同日程只合并展示，原始记录保留；近似名称、不同时间、地点冲突不视为完全相同。合并不得让“去重后排除关联副本”吞掉整组内容。

## 6. 交付门槛

修改者必须完成以下核对，并在验证记录中给出结果：

1. 读完目标页面和直接公共组件；检查已改页面没有新增原生默认弹窗、裸像素内距或多行胶囊文字墙。
2. 运行本次影响的布局、状态与数据检查；执行 Android 编译与 lint。检查通过只证明代码契约，不代表实际渲染通过。
3. 有设备授权时，检查浅色／深色、长标题、空值、大字体、首尾长按与快速反向切换；核对卡片内距、圆角、行高、按钮状态和文字溢出。
4. 无设备授权时停止设备操作，明确写“未真机验收”，不得以网页模拟图或静态源码断言宣称原生界面已验收。

任一强制项失败，不得将该区域记为 UI 完成。公共组件不能满足要求时，先修正公共组件，再接入页面，禁止绕开公共组件快速拼装。
