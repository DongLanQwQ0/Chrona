# UI 设计规范

适用于整个应用的页面、卡片、表单、浮层、导航和动态状态。采用主题亚克力、可调圆角、紧凑层级和连续交互。具体已确认参数见[交互基线](ui-interaction-baseline.md)，功能行为见对应[功能文档](README.md)。

## 修改 UI 前必须确定公共模式

本规范与交互基线是所有 UI 操作的强制前置。设计或修改前完整阅读两份文档及对应功能文档，确认页面类型、组件入口、尺寸和保留行为，再编辑代码。优先复用公共组件；同类页面出现差异时先修正共享职责，不复制另一套标题栏或选择栏。用户的新决定更新到本规范的对应章节及业务文档，旧描述同时修正。未确认的例外不得作为新增页面的默认实现。

**有人交互的任务中，未经用户明确允许，禁止自行拼凑或新增另一套样式。** 用户要求实现功能，不等于允许偏离本项目的页面语言。既有组件不能满足要求、确有必要调整样式时，先说明具体差异、原因及影响，向用户问清楚后再做；不得先实施后补问。无人值守任务是例外，可自行决定必要的样式调整并记录采用的方案。

2026-10-19 晚间确认的收紧方向贯穿下述规范：首屏优先呈现内容、关联操作合并、同类页面统一结构、顶部位置与 Lucide 图标一致、静止留白和动画空间独立验收。此前确认的圆角档位及完整交互基线继续生效。

## 一致的视觉语言来自公共组件

颜色、表面、字体、圆角和反馈由公共设计系统提供。新增界面组合现有组件；组件存在缺陷时在其职责范围内修正，避免逐页复制另一套实现。图标使用统一 Lucide 资源，主操作、选择态和强调内容使用当前主题色；深浅主题下保留清晰对比。

网页与原生共用矢量源：图标由原生VectorDrawable生成，保留其填充、描边和分组几何；品牌使用项目已有SVG，不另画一套近似素材。网页默认同步手机完整配色，独立外观仅作用当前浏览器；恢复跟随后继续同步，不修改手机设置。

网页同用途的Dock、筛选栏与操作胶囊沿用原生公共几何；不得由后置通用按钮样式改成小圆角矩形。公共图标使用固定方形容器居中，消除行内SVG基线空隙；操作胶囊端部只调整图标内容的视觉中心，不移动点击单元或高光。搜索与相邻计数／筛选行由一处提供间距，横屏网格不得残留空工具行。

| 职责 | 公共入口 |
| --- | --- |
| 二级设置结构、安全区与标题 | `SettingsPageLayout.content/header/show` |
| 多视图内容页标题行 | `WorkspacePageHeader`，选择栏占标题槽位 |
| 标题行相关操作 | `HeaderActionGroup`，共享胶囊、分隔与按压反馈 |
| 配色、文字、卡片和表单 | `UiStyle.colors/title/muted/card/input/button/toggle` |
| 浮层、长内容和开合 | `UiDialogs.dialogPanel/dialogBody/showFloatingDialog` |
| 选择与导航 | `DockNavigationLayout` 及其 motion host |
| 日期区间切换与日期选择 | `DateIntervalBar`、`UiDialogs.dateDialog` 与公共自定义选择器 |
| 列表批量选择 | `BatchSelectionUi`，复用主页日程／收件箱的同高计数行、短动作、圈勾与显隐 |

公共实现的职责与接入见[公共 UI 库](ui-library.md)。`UiStyle` 管主题与控件语义，`UiSurfaces` 管渲染与采样，`UiDialogs` 管浮层，`UiMotion` 管内容动效；页面不复制这些机制。整理按功能等价验收，不改变本规范与交互基线。

### 页面基本语言必须先于局部布局

- 新页面先选择本规范已有的页面类型，复用相同层级的标题栏、图标操作、内容边界、表面、字体、圆角及反馈。页面身份和视图选择不重复占行；必要的页内动作在其作用对象附近表达。
- 同一用途使用同一公共组件：日期或时间段前后切换使用 `DateIntervalBar`，视图选择使用 `DockNavigationLayout`，菜单使用公共浮层，搜索和排序使用既有输入与选择入口。不得把几个外观各异的普通按钮拼成同用途的替代控件。
- 固定标题、正文视口和底部浮动选择栏各负其责。底部栏的完整动效包络、末项可达空间和浮动操作位置按实际尺寸安排；不以不透明占位条、缩字或裁切动效遮掩布局问题。
- 图片展示框按原图比例贴合可用宽度，图片零内距铺满自身容器，只由一层公共圆角裁切；PPT不得通过裁字、拉伸或固定高度的双层圆角外框制造填充。全屏查看沿用现有图片页面的缩放和保存能力，以及统一标题操作与安全区，不另造查看页。
- 图片左右切换必须在拖动过程中实时跟手并呈现相邻图片，松手后提交切换或平滑回弹，取消、多指及首尾边界不误翻页。放大后优先平移图片；点击实际图片边界外的空白可关闭大图，图片内单击和标题操作不误关，双击缩放与保存继续可用。
- 图片附件与课堂PPT统一复用`AttachmentViewerActivity`的查看交互，不按入口分叉布局。横屏隐藏系统状态栏和重复标题，图片视口铺满整个窗口，延伸到摄像头／刘海区域；返回／保存沿用48dp公共图标按钮，分别浮于安全区域左右上角，左右20dp、顶部16dp，安全区只约束操作而不裁掉图片。系统栏可按系统手势临时唤出，离开查看页恢复，保存返回后继续横屏查看；竖屏保留公共标题结构。
- 大图缩放围绕手势焦点连续变化，缩回100%也不重置为居中矩阵；只修正超出可浏览范围的边界。放大时先平移图片，横向到达边缘后的剩余拖动交给同一图库轨道，邻图跟手进入，松手定页或回弹；竖向拖动、双指和取消不误翻页。
- 图片附件与课堂PPT共用长按拖放；稳定显示的当前图片可提起为保留比例、沿用公共圆角的系统拖动预览。移动翻页、缩放及多指手势不触发拖放，接管后不误点击或翻图。仅向接收目标临时授予所拖图片的只读URI，不传私有文件路径，也不扩大同步数据访问范围。
- 正文切换与图片切换使用既有 `UiMotion` 和已确认交互参数，尊重系统减少动画；导航、输入控件及正在阅读的内容不因局部刷新重建。新增内容与状态更新保持用户当前滚动偏移和焦点，滚动只响应用户明确操作及首次进入的既定定位。
- 页面上只放用户需要查看或操作的内容；不增加解释布局、技术来源或实现方式的小字。读不清、操作不易发现或状态不明确时，修正结构、层级和反馈，而不是叠加说明。

`HeaderActionGroup` 两端图标按圆角后单元的可见面积居中，完整点击单元保持原尺寸；中间分隔统一为 1dp，不通过单页偏移或额外分隔边距修正。圆角档位变化时由公共组件重新计算。

胶囊内容居中只影响内容内距，不平移整颗子控件或前景高光。透明子按钮高光填满自己的单元，再按祖先表面的完整变换矩阵与圆角裁切；内部分隔处不额外套小圆角。整组按压、条件按钮缩放与祖先位移时，高光和表面仍使用同一坐标系。

## 布局遵循同一内容轴和间距层级

页面先确定内容区域，同组控件共享对齐轴和宽度策略；可用宽度由容器统一分配，而非各控件临时计算。同级表单行视觉高度一致，多行内容按需要增高。紧凑通过信息取舍和内部间距实现，不挤压文字、缩小操作区域或制造大块空白。

课堂／历史／监视的卡片列表使用SettingsPageLayout.motionViewport：视口扩到页面实际可用边界，原20dp沟槽同时承载按压放大；宽屏只取满足PressFeedback.edgeSpace的最小内距，不叠加双重留白。列表顶部保留8dp以容纳原卡片峰值和批量行向上过渡；中间布局与视口的children／padding不裁切放大内容，视口以独立clipBounds保护真实外边界，课表网格尺寸保持。

布局、绘制和触控范围分别管理。动画的空间由层级与绘制区域承载，不反过来挤窄静态内容或永久撑高每行。中间容器容纳其子项的完整动效，最终视口仍保护真实边界；优先复用组件提供的承载方式。

### 页面顶部与返回／确认使用同一基准

顶部位置从状态栏、刘海等系统安全区的下边缘计算，不能从截图或整个屏幕的顶边直接比较。安全区只由一层容器处理，页面不得重复叠加状态栏高度。

- 原生页面内容左右各 20dp，顶部 8dp；公共标题行最小高度 64dp，48dp 返回／确认按钮垂直居中。正常字号下按钮上边距安全区 16dp，图标中心距安全区 40dp。同一行的左右动作必须共用中心线。大字体需要增高时整行自然增高，左右动作仍对齐。
- 二级设置页将返回与标题合为一行，复用 `SettingsPageLayout`；标题栏后保留公共 16dp 间距。禁止额外增加独立返回行、重复大标题或解释型副标题。首个分组不得再叠加一份顶部间距。
- 系统安全区与键盘占位由滚动视口外的公共安全区容器承担，使视口实际高度等于可用区域。键盘展开后，聚焦字段必须能完整滚到键盘上方；不能仅为全屏滚动视口增加底部 padding。
- 所有页面返回使用 Lucide `ic_arrow_left`，确认／保存勾选使用 Lucide `ic_check`，统一 24dp 图标、2 单位圆端描边与 48dp 点击区域。使用 `UiStyle.navigationIcon`，禁止用文字字符 `←`、`✓` 或另一套图标替代。日期上／下段导航继续使用方向 chevron，其含义与页面返回不同。
- 捕获页退出仍执行草稿保护，详情页确认仍执行原保存流程，网页返回仍优先处理网页历史；统一外观不得改变操作语义。

### 首屏优先留给主要内容

手机顶部与首屏空间优先用于用户正在查看、比较和操作的内容。布局先确定第一条记录、第一行网格或主要正文出现的位置，再安排标题、导航、筛选和工具。常规字号下，主要内容应在首屏上部开始，不能让多层工具栏和空白占去大半屏。

- 工作区标题槽与两侧返回／刷新按钮之间统一保留 8dp，由 `WorkspacePageHeader` 提供；选择栏内部 6dp 留白和运动参数保持不变。条件刷新按钮退出时渐隐缩小并同步收起宽度及相邻间距，隐藏后无空槽；反向切换从当前进度继续。
- 同一层级的标题与视图选择合为一行；选择栏已表达页面身份时，不再另占一行重复标题。当前范围或分组名称可作为可点击的内容标题，不另建全宽按钮。
- 相关图标操作合入标题行的共享胶囊，以细分隔区分点击区域。开关使用明确的选中态、提示和无障碍状态，避免仅为一个开关增加整行标签。
- 相邻区域只由一个容器负责间距，按实际可见边界核算。不得叠加上一区域的底部 margin、下一区域的顶部 margin、透明占位和动画 padding。
- 紧密关联的文字、计数和内容使用 4–8dp 间隔；一般相邻控件保持 8dp。二级设置标题后的 16dp 仍由公共标题栏提供。空状态接续工具栏向下排布，不通过垂直居中制造大片顶部空白。
- 动画包络复用标题行与相邻区域的安全空间。紧凑布局可使用 `motionHost(true)`，须确保实际视口内有足够空间、放大不遮住相邻文字；不能用关闭视口裁切或缩减已确认动效来换取紧凑。
- 标题槽及工作区底部选择栏静止时四周保留 6dp 内距，高光与底板边缘清晰分离。标题槽使用 `headerMotionHost()`，选项等宽分配整个槽内底板，文字各自居中，不再为动画挤窄文字轨道。日历视图选择栏使用 `fullWidthMotionHost()`：底板和选项一起填满内容宽度，首尾中心距内边缘为半个选项宽度，中间中心等距。
- `WorkspacePageHeader` 将标题槽绘制在右侧刷新／取消按钮之上，高光放大或越界时不被按钮遮挡；只调整绘制顺序，保持按钮位置与点击操作。
- 2026-10-20 用户明确：保留选择栏原有样式、放大、惯性及边缘回弹；不得为防止高光出屏而增加内部轨道留白、只拉宽底板或收紧动效。上述标题槽与全宽日历栏的极端甩动允许高光伸出屏幕，交付时说明；页面内部容器仍不得额外裁掉动效。其他表单／滚动容器继续按原有包络要求验收。
- 表格或长列表中的单项按压，留白按实际会缩放的单项计算，不按整张长表的总高度计算。已有空行优先填入有用信息，避免为新增一行信息另加高度和边距。

### 按页面类型组合已有模式

| 页面类型 | 统一结构 | 空间和交互要求 |
| --- | --- | --- |
| 总览／首页 | 标题与操作胶囊 → 核心状态 → 内容卡片 | 紧凑呈现下一项的标题、地点、时间；同一信息层级不重复解释 |
| 搜索／结果列表 | 标题、搜索、操作胶囊 → 筛选 → 计数与记录 | 筛选与计数之间只留一份间隔；选择操作复用计数行，切换不推挤列表 |
| 多来源／多视图工作区 | 返回、选择栏、图标操作 → 当前范围 → 内容 | 选择栏代替重复标题；实例持久保留，刷新内容不重建正在动画的导航 |
| 日历／时间网格 | 紧凑标题行 → 共用日期栏 → 视图选择 → 网格 | 日期前后切换统一使用 `DateIntervalBar`；不另加上一段／下一段的独立按钮行 |
| 二级设置／表单 | 公共标题 → 分组字段 → 必要操作 | 使用 `SettingsPageLayout`，20dp 内容边界、16dp 标题间距；输入区域按内容增长 |
| 详情／阅读 | 标题与局部操作 → 主要正文 → 补充信息 | 不以重复摘要、全宽工具按钮或大块留白推迟正文；长内容可滚动 |
| 浮层／确认 | 标题 → 必要内容 → 同行操作 | 两个相关按钮优先同排；键盘和大字体下可滚到全部操作 |
| 下载／生成状态 | 阶段、计数、进度、耗时各占稳定位置 | 状态更新不反复改变行高；停止／重试使用局部操作，不额外堆叠按钮行 |
| 空／错误状态 | 就地状态与直接操作 | 接近受影响区域，保持最小间隔；仅显示有助于恢复的信息 |

各页遵循同一模式，不要求把信息结构不同的页面强行做成相同外观。优先修正公共组件与组合方式，功能文档只记录业务差异。

本轮页面落点按以下要求验收：

| 页面 | 必须保留的布局结果 |
| --- | --- |
| 首页 | 作业、系统日程开关、设置共用操作胶囊；下一件事的地点使用原有第二行空间，不增加卡片边距或高度 |
| 日程／收件箱 | 删除工具、筛选、计数、首条记录之间的重复空白；不通过缩字腾空间 |
| 课表 | 来源选择占标题槽位；取消重复「课表」标题及标题栏「导入 ICS」；刷新为圆形图标；学校学期为网格卡片内可点击标题；导入空状态靠上 |
| 课堂总结 | 四视图占标题槽；窄屏大字改用当前视图与公共选择面板。仅「监视」视图把运行设置合入刷新右侧的`HeaderActionGroup`；其它视图仅显示刷新。设置与分隔随公共动效渐隐缩小并收起宽度，快速反向接续，不留空槽；列表末尾与专用页不放齿轮。本地读取与切视图不显示取消X，实际远端刷新才可取消。周表复用课表网格，课堂保留搜索，历史同排排序与方向，分页统一`DateIntervalBar` |
| 日历 | 系统日程开关并入右侧操作胶囊；年／月／周／日／日程底板与选项一起填满内容宽度，等宽单元内文字居中；年历按实际字宽选择一列或两列月份，日期不得粘连 |
| 全部返回／确认入口 | 共用顶部基准、图标资源与按钮几何；检查原生设置、记录、详情、图片及网页容器 |

主页及日历／周日程操作胶囊中的系统日程开关，启用时仅将图标由次要色变为主题色，不绘制选中背景；按压与同组其它按钮复用公共填充高光及胶囊裁切，不使用独立圆形涟漪。保留原生开关语义、完整点击范围和整组按压反馈。

主页作业按钮的新作业红点绘制在图标右上角，不新增操作单元、分隔或触控区，不改变共用胶囊的几何与按压。点击有红点的入口后，将目标作业行居中并用主题色短暂强调；不通过插入说明文字提示定位。

默认避免占满一整行的普通操作按钮。两个关联操作优先同行；单个刷新、添加、导出等常用动作优先采用简洁图标按钮，独立时为圆形，相关时并入共享胶囊。图标保留可理解的符号、完整点击区域、长按提示及无障碍名称，选中状态可辨识。删除确认、无通用图标或容易误解的动作保留必要文字；长标签或大字体确实放不下时再换行。导航选项、表单输入与可点击的内容记录不按工具按钮处理。

公共确认、日期／时间与文本编辑弹窗的双按钮由 `UiDialogs.actionRow` 统一测量：可完整容纳文字与内距时等宽横排，窄屏或大字体放不下时改为纵排全宽，保持52dp最小高度并按文字自然增高，不截断标签或缩小字号。

任务详情的「重复」与删除在每张日程卡片末尾同行，删除不再占标题行；禁止在字段上方放置全宽重复按钮。重复日程页的建立／停止动作放在公共标题栏右侧，日程名称与规则共用紧凑文本区域、长内容自然换行，不叠加第二个大标题及独立规则行。月份切换复用 `DateIntervalBar`；切月与打开单次操作保留日期栏实例，打开／取消操作保留列表滚动位置。空的开始字段提示「欸~这好像还没有时间」，结束字段提示「遥遥路途，没有终点~」；提示自然换行，点击入口与无障碍名称保留。

学校作业详情不显示原始内容、图片与文件、重新解析及其背景区域；普通收件保留原有入口。新作业原子通知采用独立的信息卡样式，仅呈现作业信息与右侧 48dp 点击区域的 Lucide 关闭图标，不显示地点或完成勾选；岛上标题置于摄像头安全标题行下方，背景复用公共原子卡的壁纸／极光实现。

纵向浮动菜单统一采用传统菜单行：每项无独立底色、圆角或边框，仅以相邻项之间的 1dp 细线分隔，不绘制首尾分隔线。文字左对齐，选中项使用主题色及右侧 Lucide 勾选，点击整行；按压只显示涟漪、不放大。复用 `UiDialogs.addMenuItem/choiceDialog`，外层保留公共浮层表面；确认弹窗的提交／取消操作及包含输入字段的表单按原模式处理。

学校课表卡片的学期文字相对整张卡片居中并带文字下划线，课程数量保留右侧；数量区域在左右对称留位，不把标题仅居中到剩余区域。窄屏大字体时标题自然换行，不缩小字号或覆盖数量。

现有尺寸基准统一由公共组件维护：

| 对象 | 正常字号下的基准 |
| --- | --- |
| 页面内容 | 左右各 20dp；二级设置公共标题后至少 16dp |
| 内容卡片 | 默认圆角 22dp；内距水平 16dp、垂直 12dp；相邻记录 8dp |
| 浮层 | 默认圆角 28dp；内距 20dp；标题与正文 12dp；分组 12–16dp |
| 表单与图标操作 | 单行最小 54dp；图标触控区 48dp、图标 24dp；相邻操作间隔 8dp |
| 文字 | 页面标题 24sp、浮层标题 21sp、卡片标题 16sp、次要信息 13sp |

尺寸使用 dp/sp。大字体与窄屏按内容自然适配，保留可读性、滚动与可达操作。不同长度的选项可有不同内部宽度，高光连续适应实际范围；整体对齐不能以文字换行、挤压或过度缩小为代价。

列表筛选标签保留统一 14sp，按字宽分配单元；宽度足够时保持紧凑原布局及 Dock 动效。窄屏或大字体放不下时，在原行显示当前筛选和 Lucide 向下箭头，点击进入公共选择面板；选项及计数完整可读，取消保留原值。不得逐项缩字或用大片动画占位挤窄静态筛选区。

## 信息按任务与重要程度组织

标题、当前值、时间、来源与状态有明确层级。次要信息使用文字样式区分，整张卡片保持可读。内容容器适应信息长度。外观与配色提供五档圆角，默认第 4 档；第 2 档保留 0.15.24 的轻圆角，第 4 档恢复此前尺寸。选择栏保留已确认的圆端高光及独立 28dp 底板。

| 档位 | 按钮/输入框 | 卡片 | 面板 | 短操作 | 筛选标签 |
| --- | --- | --- | --- | --- | --- |
| 1 | 4dp | 5dp | 6dp | 4dp | 3dp |
| 2 | 8dp | 10dp | 12dp | 8dp | 6dp |
| 3 | 13dp | 16dp | 20dp | 16dp | 9dp |
| 4（默认） | 18dp | 22dp | 28dp | 24dp | 12dp |
| 5 | 24dp | 30dp | 36dp | 32dp | 16dp |

记录入口与短消息在第 4、5 档保持完整圆端。圆角值由 `CornerScale` 解析，表面、涟漪遮罩、裁切及小组件保持一致；固定图形与 Dock 动态几何独立。拖动滑块实时重绘并保存，不重建正在操作的页面。

仅保留帮助用户理解、决定或操作的内容，避免重复说明与无用副标题。列表可省略长内容，但详情必须能完整查看。状态同时通过文字、图标或无障碍语义表达，不能只凭颜色判断；未知与未完成保持不同含义。

### 按实际窗口适配横屏、分屏和键盘

适配以实际窗口尺寸为准，保留选择、搜索、排序、草稿和横纵滚动。高度不超过480dp的工作区，宽度达到600dp时将原Dock以既有纵向样式放到侧边，去掉底部遮挡；更窄的短窗口使用公共当前页选择入口。正常高度保留原底部Dock及全部动效。

短窗口日历在宽窗口将日期与视图选择同行，保留Dock；窄窗口给日期完整一行，视图选择与今天同行，使用公共选择面板。工具区复用`SettingsPageLayout.toolsViewport`约束高度并可滚动，正文保持可用空间，不缩字或剪控件。键盘与安全区占位在滚动视口外处理，焦点滚动以真实可见高度计算；浮动操作边距随当前insets恢复，不累加。

## 交互反馈连续，数据状态可信

### 横屏正文高度是强制验收项

所有新页面和UI改动必须在真实横屏／短窗口检查内容高度：记录安全区后的可用高度、固定工具高度、正文视口高度及上滑后的变化。主要内容被标题、搜索、筛选、分页等非必要固定工具挤成狭小区域，即使未越界也不通过。

横屏或短窗口的固定头＋独立正文采用公共联动滚动：向上滚动正文时，顶部标题及工具随滚动退出，正文视口同步增高；回到正文开头后向下拖动可恢复工具。不能只把工具塞进一个小滚动框而保持正文局促，也不能靠缩小正文、隐藏功能或减少既定动效解决。整页原本共同滚动的页面保留原结构；必要常驻的媒体操作与系统权限确认按各自任务验收。

验收使用真实触摸，覆盖初始态、向上连续阅读、回顶恢复、输入焦点、横向子控件与导航操作；查询、选择、滚动位置及控件实例不能因收起而重建。至少检查常用横屏与短窗口、大字体以及本轮受影响的深浅主题。未实际展示的页面标明未验原因，不以源码推测冒充全页面验收。

横屏侧边Dock与竖屏保持相同按住放大、惯性、越界及回弹。父布局必须允许完整高光越过底板和侧栏单元边界，不能通过收紧参数或裁切掩盖；首尾按住、拖出松手及快速甩动须取实际峰值帧。

按下、拖动、释放、取消和反向操作从当前视觉状态接续。位置、大小、颜色和透明度平滑变化，避免闪切、目标附近抖动和中间帧跳回。动效服务于操作关系，不替代真实状态更新；系统减少动画时仍可完成操作。

普通交互卡片按住时宽高为 1.08 倍，普通按钮为 1.05 倍；记录入口保留独立 1.20 倍。松开回到 1 倍，Dock 继续管理自己的动效。

按压与键盘焦点中的控件连同其绘制分支临时高于邻近内容，放大和高光不被后绘制的相邻控件遮挡；释放回落完成、失焦或脱离时恢复原层级。不调整布局顺序、尺寸或既定动效。主页底部 Dock、宽屏导航及工作区底部导航保持高于普通交互内容；系统窗口和浮层仍遵循各自窗口层级。

局部数据变化保留未变内容、滚动位置、输入与焦点，通过布局过渡呈现增删和位移，避免整页重建或重播入场。背景采样、圆角和模糊随真实位置与形状同步，效果层不能产生硬边、接缝、边缘光点或残留遮罩。

毛玻璃表面在每帧绘制前比较实际变换矩阵；卡片重排及祖先容器平移、缩放时，使用当前坐标重新采样壁纸。静止表面复用绘制结果，不启动持续刷新循环。

底部浮动导航叠放于连续内容之上，底板外侧保持通透；安全区与滚动内容的末尾留白保证最后一项可完整移到导航上方，不用整条不透明占位区截断页面。导航选项在可用宽度内均衡排布，保持可读字号和完整动画包络。

课堂专用监视页直接以课程名作公共标题，不重复「课堂监视」及第二份课程名。右上开始／停止与「回到最新」共用`HeaderActionGroup`，后者仅在字幕未到底部时动画展开，回底部或切到PPT时与分隔一同连续收起，隐藏即停用触摸和无障碍，不在正文叠加悬浮箭头。标题下紧凑信息行左侧放时间、地点和连接／字幕／PPT状态，右侧放「后续课程」复选框，无障碍名称保持「监视后续课程」。辅助信息与复选框使用12sp、行间2dp，操作保留48dp热区；窄屏大字自然换行，不截字或叠放。正常高度的字幕／PPT选择栏使用完整底部`motionHost()`，宿主底边为系统底部安全区加4dp，正文延伸到浮动栏下面。短窗口复用纵向Dock侧栏，信息工具可滚动；末尾保留实测导航高度加12dp，不放运行设置齿轮。

页内横向控件优先响应其自身手势；可滚动内容到达边缘后，明确交接给工作区翻页。页面主体与标题区具有一致的切页能力，系统返回边缘保持系统手势优先权。

工作区的 `DateIntervalBar` 与选择栏同属横向手势优先子项，必须在父级判定拦截前登记。日期栏左右拖动只改变日期区间，不切换工作区页面；验收通过真实触摸分发完成，不能只调用箭头的点击回调。

日期区间条在筛选面板与日程页复用同一外观、点击入口和跟手切换。相关操作组成一个共享表面，以分隔符表达边界；条件操作的出现与消失从当前宽度连续过渡，消失后不保留空槽。

日期文字的滑动严格裁切在左右箭头之间的文字视口；外层日期条、箭头和按压放大则由周围安全留白完整承载。文字裁切与控件动效边界独立维护。

日期栏最低高度 48dp；窄屏或大字体放不下完整区间时，两端日期分行显示，按实际文字高度增高，保留字号和全部日期。调用方使用自适应高度，不以固定 48dp 截掉第二行。

进度信息分离阶段、计数和耗时，以稳定位置与真实数量表达变化。高频更新合并到可读节奏，数值位数变化不改变面板高度；未知总量使用等待状态。选中填充与按压遮罩共享几何尺寸，避免按下和选中表现为两种大小。

操作范围与视觉含义一致：点击、切换和查看不互相触发，选中态反映真实值，隐藏内容不留无意义空位或仍可点击的区域。业务启用条件、来源范围与权限由统一业务规则管理，直接跳转和缓存页面也遵守同一规则。

## 变更边界与完成标准

局域网连接授权复用原生二级设置页公共标题栏与内容边界，显示浏览器类别、来源地址和四位核对码，底部并列「拒绝」「允许访问」。网页以连接状态、核对码及取消／重试操作表达流程；手输配对码收纳为默认折叠入口。应用在后台时通过普通通知进入授权页，用户确认前不连接。

以用户明确要求和已确认基线为准。不得借修复裁切、性能优化或个人审美增加限制、隐藏条件或改变功能含义；发现歧义先核对上下文，额外取舍先提出再实施。

修改前读完整的目标区域和公共组件，修改后检查实际画面及关键交互，覆盖主题、内容长度、字体适配与连续操作造成的变化。检查聚焦本次影响，避免重复无关测试。编译和替身检查支持代码结论，实际呈现需要渲染证据；不能完成时记录缺口。以上一致性、可读性或交互连续性仍有缺陷时，该区域尚未完成。

紧凑布局额外检查第一项内容距顶部的位置、可见内容量、相邻区域实际间隔和空状态起点；分别验收正常与窄屏／大字体。对选择栏检查首尾长按、拖出与甩动，确认内容更新后仍是同一个控件且动效连续。对操作胶囊检查每个按钮的实际功能、状态反馈和条件按钮收起后无空槽。不能仅以控件没有越界作为空间利用合格的依据。
