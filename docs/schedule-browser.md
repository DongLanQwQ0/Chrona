# 大量日程浏览（0.13.41）

## 使用方式

- 日程按日期分组，无日期事项显示为「待安排」。保留即将到来、待安排、较早的，新增全部入口。
- 顶部日期条可切换月份，点击日期条使用已有自绘滚轮跳转指定日期；「今天」直接查询今天的事项。
- 筛选浮层提供时间范围（全部、今天、本周、月份、单日、自定义）、类型、写入状态和来源，各条件共同生效。指定日期与自定义区间自动切到全部，避免历史日期被即将到来条件隐藏。
- 拾时日程在 SQLite 完成筛选、排序与分页，每页 24 项，底部上一页/下一页切换。固定页大小限制 View 数量，避免不断加载后堆积整个历史列表；沿用毛玻璃卡片与筛选进入动画。
- 全选仍覆盖当前筛选的所有拾时日程，跨页选择保留；改变筛选会重新计算匹配 ID。返回任务详情后保留筛选、页码与滚动位置，旋转时保存日期、类型、来源、状态、关键词和选择。
- 系统来源保持只读，排除拾时已关联的事件，点击打开日历。默认查所选月份，可切换日期范围，最大一年/1000 个实例；权限不足不显示旧缓存。系统来源仅有系统活动类型和已存在日历中的状态，不虚构待办分类或待确认收件。

## 数据与性能

- `ScheduleQuery` 生成参数化查询，同一筛选用于页数据和全部匹配 ID。只有本页加载完整字段；全选 ID 查询不加载标题或备注。大量批量删除按最多 400 个 ID 一批读取。
- 普通日程使用当地起止边界，全天日程使用 UTC 日期边界；日期范围按区间相交匹配，包含跨日事件。关键词中的 `%`、`_`、反斜线按普通文字查找，保留中文类别标签搜索。
- 相同日期/时刻用 ID 做稳定次序，NULL 日期最后，翻页不因同刻事件而重复或漏项。日期分组和当前月份导航取代单一长列表；当前页仍使用现有 ScrollView，不新增列表依赖。
- 首页也改为限量查询近期时间线和下一件事，关联系统 ID 只读 ID 列；页头数量改用 SQL COUNT。
- 数据库 v8 新增时间/状态索引和修改计数表。任务、候选、图片和文件记录的增删改通过触发器计数；五秒轮询读取计数，时间条件每分钟更新，避免全量实体读取。无变化不重绘。
- v6、v7 备份在暂存数据库内依次迁移到 v8，保留旧记录。系统缓存绑定日期窗口，异步旧窗口结果不用于新月份；横滑期间推迟重建列表。

## 页面缓存（0.13.42）

- 首页、收件箱、日程各保留一个页面视图，首次访问创建，之后滑动和底部导航复用；取消滑动也保留已创建的邻页。最多三页，随 Activity 销毁释放，避免启动时同步创建三个页面。
- 切页不再二次重建或强制返回顶部，保留纵向滚动、内部横向滚动、搜索、筛选及分页状态。筛选参数保持在 Activity 中，隐藏页的旧快照不能覆盖新设置。
- 数据修改计数、时间边界、主页设置和日历读取权限变化时刷新对应旧页面；系统日历异步结果使首页和日程缓存失效。滑动过程中延后刷新，返回前检查页面版本。
- 搜索监听绑定所属页面；滚动恢复与选择栏动画绑定原控件，避免延迟回调操作切换后的页面。

## 紧凑筛选（0.13.43）

日程页删除描述文字和两行日期/筛选栏，仅显示「未来、安排、以前、全部」和右侧筛选图标。统一毛玻璃浮层集中日期范围、日期跳转、今天、类型、写入状态、来源及重置。

日期范围上左滑向后、右滑向前：单日一步一天，本周一步七天，月份一步一个月，自定义范围按包含结束日在内的天数整段平移。全部日期未限定范围时不步进；系统来源的全部日期实际是月份，可按月步进。系统区间移动后继续校验一年上限，超限保留原范围。

「安排」沿用原待安排语义：缺少开始或结束时间；不等于待确认或未写入日历。「未来」包含仍未结束的日程。日期区间筛选需要开始时间，未定开始时间的事项应在全部日期下查看。

`checks/ScheduleRangeStepCheck.java` 检查单日、多日、周跨年、月份及闰年边界和固定天数跨闰年的一年限制判断。未进行手机触摸、视觉或动画验收。

## 验证边界

### 日程卡片（0.13.47）

首页时间轴、下一件事和日程结果共用属性行：标题最多两行，地点独立显示（为空时隐藏），来源使用具体日历名或“拾时”。首页标题 16sp，底部类型与来源 13sp；时间留在时间轴外侧，下一件事另有时间行。日程结果标题 17sp，类型放在标题右侧，时间和地点 14sp，底部来源与写入状态 12sp。首页仅在尚未写入且 AI 标记不确定时显示待确认提示。

属性使用现有 SVG 路径的 Android VectorDrawable，统一 24 单位 viewport、18dp 控件、6dp 图文间距，主题 tint。多行属性图标对齐第一行中心，单行属性垂直居中；空地点/来源隐藏，长文本省略。保留原有点击、系统日历只读跳转与多选操作。已执行编译与静态检查；实际设备上字体缩放及长标题显示仍需验收。

### 筛选交互（0.13.46）

日期快捷按钮与第一条分隔线之间留 12dp 间距。类型、日历状态和来源的选项使用 220ms 高度/透明度展开收起动画，箭头同步旋转；快速反向操作取消旧动画，关闭系统动画时直接更新状态。

日期范围内两端使用 SVG 路径的 Android 矢量箭头，删除文字操作提示，保留无障碍描述。中间文字独立于箭头，限制在中间裁剪区，横拖跟手移动；未过阈值或取消则归位，跨区间后旧文字移出、新文字从相反方向进入。日期步进仍使用原有草稿逻辑和一年限制。

### 弹窗层级与选择样式（0.13.45）

共享弹窗管理现在同时跟踪弹窗内容层。打开子浮层会模糊并淡化已存在的父浮层，增强子面板的渐变遮盖，避免父面板文字穿透日期滚轮；关闭子浮层恢复父面板的清晰度和透明度。Activity 的缩放/模糊仍在最后一层关闭后恢复。

筛选的选中和未选中按钮共用带边框的毛玻璃控件，通过主题混色表示选中。设置行展开箭头改用统一矢量图标，移除字符箭头。Android 12 以下通过父面板淡化和子面板更高遮盖量提供层级区分。未进行真机视觉验收。

### 筛选面板（0.13.44）

- 「安排」改为「未定」。`ScheduleFilterSheet` 封装筛选界面，日期快捷项一行展示，类型、日历状态、来源以图标/名称/当前值三列排列，选项直接在原浮层内展开。
- 首页系统日程卡片省略「系统日历 ·」前缀，仅保留日历名称与地点；两项均为空时不创建空副标题。
- `ScheduleFilterState` 保存独立草稿；重置、选项和日期滑动仅改草稿，应用时一次提交。点击外部或返回取消，不改变列表与权限；读取系统日历权限仅在应用系统来源时申请。
- 起始/结束日期使用现有自绘选择器，打开子浮层时不关闭筛选面板。取消任意日期选择不改原区间；两个日期都确认后才更新草稿，异步回调检查父面板仍显示。
- 日期范围仅在有限区间显示，并附滑动/点击提示；全部日期不显示无效滑动入口。滚动正文限制高度，标题与应用按钮固定在正文之外。系统来源的类型/状态显示其真实固定含义。
- 日期窗口与区间步进共享生产逻辑。纯 Java 检查覆盖草稿取消/重置隔离、含结束日的平移、系统月份默认值与超限步进不改变状态。编译和 lint 可验证；未做真机层级弹窗、触摸或视觉验收。

`ScheduleQueryCheck` + `checks/schedule_query_check.py` 将生产 Java 条件交给真实 SQLite 执行，覆盖 4000 多条同刻事件的升降序分页、组合条件、文字通配符、中文类别、跨日和夏令时/全天边界。脚本执行生产迁移方法构造出的 SQL，检查旧数据保留、修改计数、事务回滚和数据库备份后的触发器。

Gradle assembleDebug / lintDebug 检查最低 API 兼容性。未执行手机 UI、厂商日历 Provider、升级安装或 ZIP 导入的真机验收。SQLite 默认大小写折叠主要针对 ASCII；中文及英文搜索已检查，复杂非 ASCII 大小写映射未扩展。

归档、待办完成状态不在本轮范围；不把「较早的」当作「已完成」。
