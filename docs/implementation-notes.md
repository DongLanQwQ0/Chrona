## 当前功能

- 使用引导以六步带用户认识页面、配置 AI、记录第一件事、逐项审核、开启日历提醒和日常维护。每步提供具体操作与完成结果，上一步/下一步按钮固定在底部，可跳过；可复制练习示例并直达 AI 设置、记录和备份页面。首次启动及从旧版升级后显示新版教程，设置里可随时重看，旋转保留当前步骤与滚动位置。引导显示后再请求首次权限。
- 首页、日程列表和桌面小组件按具体日程 ID 定位详情；一条收件生成多项日程时，点击第二或第三项会打开对应页，旋转与后续刷新保留当前页。
- 设置提供 GitHub Release 更新检查、说明和 APK 浏览器下载；默认每天后台检查一次，同一新版本只提示一次，可关闭自动检查。暂未发布、网络失败或非法版本信息会显示检查失败，不会误报「最新版本」。更新源为 `DongLanQwQ0/Chrona`，发布方法和签名要求见分发文档。
- 应用内文字输入、Android `text/plain` 分享入口；每条输入先存入本地 SQLite 收件箱。记录页顶栏左为返回、右为 ✓ 保存，剪贴板、图片、文件三个入口以图标形式排在「记录一件事」标题右侧。
- 收件箱可一键读取剪贴板文字（追加到输入框）；不再提供按行拆分多条，一次提交即一条输入。
- 图片输入：可从系统分享菜单接收图片，也可选择相册图片或截图；图片存入应用私有目录并缩放到长边 1568 px、JPEG 质量 90 后随请求发送。支持「只发图片」的输入。若服务拒绝带图片的请求，应用会判定该「地址 + 模型」不支持图片并停用图片入口，可在设置中重新启用。缩略图右上角的移除按钮为 36 dp 的小圆形 `×`（记录页与任务详情共用）。
- 普通文件：记录页和任务详情支持从系统文件选择器添加 ZIP 等文件，也支持通过 Android 系统分享进入；记录页支持多图选择和待提交文件列表，Android 10+ 普通文件保存到公共 `Downloads/Chrona`。详情可打开、另存副本或解除任务关联，删除附件前会确认；普通文件内容不会发送给 AI，提示中仅包含文件名、MIME 类型和大小。
- 按需联网检索（输入含链接时）：解析前自动抓取链接正文作为上下文，用于补全网页上才有的时间、地点与报名信息。上限为每条输入 3 个链接、单页 512 KB、正文合计 4000 字，只接受 http/https；微信文章优先抽取正文并识别验证/异常页。混合输入读取失败仍可解析原文；仅链接且正文不可读时停止模型请求并提示补充正文或截图。任务详情显示抓取时间、字数与摘要，并提供「重新联网检查并解析」入口。
- `JobScheduler` 异步处理输入，网络可用时调用兼容 OpenAI Chat Completions 的自定义 HTTPS API；一次输入可返回多条草稿，记录服务返回的 token 用量。
- API 基础地址、模型名和密钥由用户填写。密钥以 Android Keystore 的 AES/GCM 加密后保存在本机；不要将真实密钥写入代码或文档。
- 日程草稿在应用内确认或修改后，写入应用专属的本地系统日历；支持继续在应用内更新已写入的日程。时间不完整的草稿不会自动写入。
- 日程草稿可归类为活动、待办、提醒、截止或备忘；「收件箱」可按类型和状态筛选历史输入。详情页支持全天日期编辑（结束日期含当天），写入系统日历时自动转换为 UTC 零点及排他结束日。
- 程序补全缺失的结束时间：活动、待办、提醒、备忘分别默认 60、30、5、15 分钟；截止类保留截止时刻，开始默认前移 1 分钟。自动结束时间带来源标记，可跟随开始时间和类型变化；AI 明确提供的结束/时长和用户修改的结束时间保留，旧数据也保留。起止字段点击打开日期/时间选择器，全天只选择日期，取消不修改。截止标题与默认提前提醒由程序生成，显式不提醒和提前 0 分钟均保留。
- 主界面分为「首页 / 收件箱 / 日程」三个板块。首页以独立时间线展示近一月日程事件，空日期不占位；收件箱从独立入口进入，入口旁显示待确认数量。收件箱用状态胶囊筛选，类型菜单收在漏斗按钮中（类型选择弹窗为窄版、行文字居中）；日程用「即将到来 / 待补全 / 较早的」页内分区；长列表每次展开 12 条。记录输入、任务详情、设置、外观、AI 服务与诊断作为二级页面。
- 外观支持跟随系统、浅色与深色模式、多种预设主题色、自定义颜色和 Android 12+ 系统壁纸配色；预设配色以两列网格排列。卡片与 Dock 使用进程级缓存的静态壁纸模糊，可选普通/高斯算法并调节强度；面板混色浓度可调。主题切换原位刷新文字和壁纸遮罩；选中项保留亚克力效果并使用当前主题色强调。API 31+ 弹窗可实时模糊页面背景。手机 Dock 悬浮并留出底部安全间距，记录入口由 `UiStyle.recordEntry()` 统一构建（手机端与宽屏是同一个亚克力圆形 `+` 按钮，只有图标、主题色着色、无文字无实色）；大屏使用侧边导航。Android 15+ 页面为系统栏留出安全区域。
- 首页月内时间线可设为 5–50 项（默认 20），按时间顺序列出近一月日程事件并隐藏空日期；下一事项支持横滑浏览最多 5 件。收件箱保持独立入口，无记录时显示空态引导。
- 收件箱与日程页在页面标题和设置按钮之间提供搜索框，按关键词过滤当前标签/筛选的列表（日程匹配标题、地点、备注与类型，收件匹配原始输入与链接正文）；紧邻的时间排序只用一个箭头表示（↑ 最早在前、↓ 最近在前），并与设置按钮共用同一个胶囊控件。搜索词与排序方向随页面状态保存。
- 首页、收件箱、日程三页之间可直接左右拖动切换：拖动时相邻页同时跟手预览，未达阈值回位，与任务详情页的左右切换一致；从筛选胶囊行、类型筛选行或「下一件事」横滑条内部起手的横滑仍由这些横滑控件处理。已在端点（首页向右、日程向左）时按 0.3 阻尼跟手并在每帧重绘亚克力表面，拖动与切换动画中卡片模糊都会跟着页面走。首页不再单独显示待确认数量：待确认与失败之和显示在下方 Dock「收件箱」右上角的半透明角标，收件箱筛选胶囊的「待确认」「失败」也各自带数量。
- 设置页提供 DeepSeek Flash/Pro 快速填充；模型名称与 API 地址仍可自行编辑。已知 DeepSeek Pro 不支持视觉时隐藏图片入口；未知模型仍沿用请求拒绝后的识别规则。
- AI 服务设置支持 JSON 配置导入导出：API 地址和模型始终导出；API Key 由默认未选中的复选框控制。无 Key 配置可导入到新设备后补填，已有本机 Key 在导入时保留；导入前展示覆盖范围。
- 设置中新增独立的完整 ZIP 备份与恢复：包含全部收件箱/日程草稿、已存原始图片、普通附件文件内容、模型输出和非敏感设置。API 密钥默认不备份，只有显式勾选才写入 ZIP；壁纸图片不打包。跨设备恢复会在本机公共 `Downloads/Chrona` 重建普通附件，并按标题/时间等信息重新关联系统日历；缺少日历权限或无法重建的事件会保留为待确认。导入前校验备份，恢复失败会尝试回滚本机数据；公共附件不会因为恢复或删除任务而清除。
- 当 API 报告缓存命中 token 数时，在详情页展示本次命中数和输入 token 数；未报告时不推断命中率。
- 日程删除：可逐条删除草稿（已写入日历的会同时删除系统日历中的对应条目），也可整条删除一次输入及其全部草稿；删除输入会取消仍在排队或运行中的解析。
- 收件箱支持长按任务进入多选，可选择当前筛选结果并批量删除。已写入系统日历的关联事件会先删除；日历服务报错时保留对应收件并报告失败数量。
- 任务详情支持在收件箱任务间左右滑动分页；模型实时输出可在独立的有限高度窗口内纵向滚动，不会被详情页外层滚动抢走手势。
- 详情页使用图标化操作，备注在浮层中编辑，模型日志支持滚动；清理了多余弹窗。
- 解析结果通知与失败重试。处理结果走 `chrona_results` 渠道（`IMPORTANCE_HIGH`、`CATEGORY_REMINDER`），会以悬浮通知弹出；解析进行中的常驻通知走 `chrona_parsing`（`IMPORTANCE_LOW`），不会弹出。日程提醒使用系统日历。
- 解析中输出预览只显示答案，只有思考时提示等待；预览最多读取答案尾部 12 KB，每 1.5 秒增量刷新。完整输出保留思考的空格和换行，只格式化答案 JSON，再按 16 KB 分页；不变文件复用格式化缓存。首次完整输出/文件变化时仍有同步格式化开销。明确不支持的请求参数最多降级一次，复用同一输入和时间锚点。
- 外观页可用本地图片作为页面背景（可随时恢复默认）。图片按需降采样到长边 2048 后居中裁切绘制，并叠加主题色罩与光斑，保证卡片文字始终可读；换主题、切换浅色/深色都会一并生效。
- 设置页可导出/导入配置：导出文件总是包含基础地址与模型，是否包含 API 密钥由一个**默认不勾选**的复选框决定（不勾选时密钥不写入文件）；导入前会先列出文件里有什么并要求确认。外观（显示模式与配色）一并导出，自定义背景图属于本机资源所以不导出。
- 主题配色会即时应用到所有存活页面：修改配色后返回任意已有页面都是新配色，不再出现「只有外观页变了、其它页还是旧色」。
- 诊断（仅测试版）：设置内的「诊断信息」页面汇总版本/机型、AI 配置（不含密钥）、数据库真实结构与记录数、附件占用、待处理解析任务，以及进程内事件日志；「复制全部」可直接粘贴反馈。事件同时写入 logcat 与 `files/diagnostics.log`（128 KB 轮转）。

通用联网搜索（对模糊任务做开放式检索）按用户决定暂不接入第三方服务。自定义服务的图片能力仍只能在请求被拒后推断；链接抓取只做正文抽取，不执行页面脚本，重脚本页面可能取不到有效内容。缓存命中统计取决于 API 是否返回相应字段。


## 后续接力重点

1. 先读本文件、[HANDOFF.md](../HANDOFF.md) 和 [CHANGELOG.md](../CHANGELOG.md)，再查看对应模块代码；不要将历史需求当成已完成功能。
2. 通用联网搜索按既有决定暂不接入；当前开发重点是真机回归新增的历史分类、全天日程编辑与界面，以及既有输入、日历和后台处理闭环。
3. 当前数据库版本为 4（新增 `event_candidates.category`、`event_candidates.all_day`、`tasks.cached_tokens`）。手机上的版本 1/2/3 数据靠 `TaskStore.onUpgrade` 的顺序 `ALTER TABLE` 保留；以后改表必须继续追加迁移，不能直接删库或只改 `onCreate`。
4. 真机回归至少覆盖：多个草稿、时间不确定、API 错误与重试、日历权限拒绝、已写入日程的应用内更新、删除后系统日历不再残留条目、剪贴板读取与按行拆分提交、**从 0.1.0/0.2.0/0.4.0 升级安装后既有数据仍在**、分享图片与选图、模型不支持图片时的降级提示、语音识别追加文字、含链接输入的抓取与「重新联网检查并解析」、**应用被系统杀掉后「解析中」输入能自动转为失败并可重试**、**提交后切到后台解析是否完成（含常驻通知是否出现与撤下）**。
