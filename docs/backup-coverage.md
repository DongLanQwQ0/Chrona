# 备份包含哪些内容

需要保留作业、课表和历史时，使用「完整数据备份」；仅复制外观和服务偏好时，使用「配置备份」。

| 内容 | 配置备份 | 完整数据备份 |
| --- | --- | --- |
| 主题、背景及已有服务设置 | 包含 | 包含 |
| 提醒总开关、系统提醒、原子岛来源开关、壁纸背景、胶囊倒计时与秒数 | 包含 | 包含 |
| 首页待办展开、日历系统来源开关、周图片附带日程索引 | 包含 | 包含 |
| 收件、日程、完成状态、原文及附件 | 不包含 | 包含 |
| 导入课表、来源选择、课程关联及校历配置 | 不包含 | 包含 |
| 作业远端映射、忽略标记、更新历史与统一收件绑定 | 不包含 | 包含 |
| 学校课表缓存及课程备注 | 不包含 | 包含 |

学校绑定只保存随机标识及其匿名映射，不导出学号、密码、Cookie 或登录会话。恢复完整备份后学校自动同步保持关闭；检查账号与来源后再开启。同一账号重新登录可继续使用原作业收件绑定。

提醒的临时槽位、当前通知、延后计时及运行中的服务不复制。恢复时清理提醒运行状态，保留已恢复的静态外观开关，再按日程重新建立提醒。

系统日历 ID 属于当前设备，换设备后需要重新核对来源开关和日历关联。备份不是系统日历服务自身的数据导出。

恢复前校验配置和学校数据结构；失败时恢复原配置与课表快照。本轮使用合成数据验证往返和失败路径，未用真实数据库进行覆盖恢复。
