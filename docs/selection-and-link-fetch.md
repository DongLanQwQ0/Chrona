# 多选与来源正文读取（0.13.37）

- 收件箱和日程列表长按进入选择，点选/全选后确认批量删除。返回手势或返回键取消当前选择；API 33+ 使用 OnBackInvokedCallback，旧版本保留 onBackPressed。日程删除保留原始收件，清理所选系统日历关联并重新计算收件状态。
- 事件日志内部滚动容器在 dispatchTouchEvent 的 DOWN 阶段保留手势，直到 UP/CANCEL，避免可选中文本绕过 OnTouchListener 后被外层页面截获。
- AI 服务删除独立配置导入导出及专用表单导出代码；已保存设置和无密钥恢复草稿仍由统一 ZIP 备份管理。
- 来源抓取使用移动网页请求头；微信公众号优先抽取 js_content，排除验证、环境异常和已删除提示。每次最多 3 个链接，单页 512KB，合计最多 4000 字。异常提示不传给模型；纯链接且没有有效正文、图片或附件元信息时提前结束请求，混合输入保留可用内容并提示抓取失败。
- 来源弹窗可以打开原始链接。需登录/验证或只有脚本渲染的页面不能保证自动读取；可复制正文或添加截图。没有新增第三方抓取服务。
- 验证：LinkFetcherCheck 覆盖正文嵌套、异常页拒绝、误判和纯链接检测；Gradle 编译与 lint。用户给出的微信链接在当前环境无法直接打开，未确认实站抓取成功；未执行真机手势验收。
