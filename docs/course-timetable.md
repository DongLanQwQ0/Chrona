# 本地课表

入口为首页「今天的安排」。TimetableActivity 复用 UiStyle、主题色、安全区、玻璃日期选择器与浮窗；TimetableGrid 的课程视觉保持 0.13.83 样式。TimetableLayout 负责实际时间映射和冲突分列，长课连续、空闲时段压缩，大字体和冲突时允许横向滚动。

手机课表保留标题、返回、导入与学期选择，不展示导入文件名和时区元数据行。同名课程在相同星期及起止时段且实际日期互斥时合为一个色块，单双周不同地点不再占用并列窄列；同日同时异地的真实冲突保留并列色块。地点一致时显示公共地点，地点变化时色块只显示课程名，详情按实际日期列出地点。原始安排及其地点、时间和身份保持完整，首页、小组件和统计仍使用实际安排。

## 学期与导入

AcademicTerms.Plan 表达学年、秋冬／春夏或单学期、开始日期、第二学期开始日期和结束日期。优先从 X-WR-CALNAME 提出学年与类型建议；缺失时按课程最早日期提出建议。两学期文件默认以第一周周一加 8 周提出分界，必须在导入浮窗中确认，可调整全部日期及类型。起止范围必须覆盖全部课程；跨午夜安排按开始日期归属学期，网格仍按日拆分。

用户确认的示例秋冬文件在 2026-09-14 开始，分界为 2026-11-09。日期来自通用建议与用户确认，未作为应用内硬编码校历。一次导入支持一个学年的半学年或单学期；全年课表请分别导入秋冬与春夏文件。

同学年同季节为替换单位，预览列出将替换的学期；其他学期及其分类保留。每份原始 ICS 仅保存一次，以 enabled 标记仍保留的学期。支持删除单个学期及最后一个学期。首次进入按当前日期选择，假期选距离最近的有课学期，随后保存选择。

## 常规与特殊安排

相同标题、地点、星期、开始时间与时长，在所选学期至少有 3 个不同日期、跨度至少 14 天时，建议进入常规网格。其余安排在下方按日期列出；不会按周末与否区分，也不会擅自认定为考试或调课。特殊安排分页显示，每页 20 项。

详情可以把色块包含的日期移至特殊安排，或把一项特殊安排放入网格；「管理」可恢复当前学期的自动分类。分类只控制展示位置，不删除课程、不改原始时间。总时长根据实际起止时间及时区计算，包含特殊安排；按课程名统计门数，相同实际安排不重复累计时长。

## 解析与持久化

TimetableParser 使用 [biweekly 0.6.8](https://github.com/mangstadt/biweekly) 读取 iCalendar，依赖 vinnie 2.0.2，均为 MIT 许可；上游 JAR 包含许可证和嵌入代码声明。未使用 jCal，排除 Jackson。

解析支持有限日/周/月/年重复、BYDAY、COUNT/UNTIL、RDATE/EXDATE、单次修改和取消、UTC/本地/命名时区、全天及跨日事件。学期导入要求有限日期，拒绝无限重复，以免统计不完整；复杂无限规则、多重 RRULE、EXRULE 和范围修改仍明确拒绝。

上限：单份 UTF-8 ICS 1 MiB、5000 个原始事件、30000 次展开、512 个源展示色块、解析预算 10 秒；最多保留 12 份源文件，持久快照不超过 12 MiB。course-timetable.json 原有 format/ics/name/zone/importedAt 字段保持有效，新增 plan/enabled/classification/archive/selected 配置；原本只保存 ICS 的文件按当前建议建立分组，不丢失原文。AtomicFile 写入失败保留旧数据；完整备份预检所有源和学期配置并支持失败回滚，清单上限为 20 MiB。

## 验证

0.13.85：`CourseAgenda` 将所有启用学期的实际安排提供给首页与小组件，包含特殊安排，独立于用户当前浏览学期；跨源课表按标题、地点、实际起止与全天标记去重。来源仍为课表，不写系统日历，也不启发式合并外部同名日程。点击携带学期 ID 与 occurrence key 定位详情，过期入口保留可用课表页面并提示。

`TimetableStore.load()` 缓存解析结果；成功保存、删除、恢复和回滚时清缓存并刷新小组件。`revision` 为无锁可见的单调版本，主线程查询不会等待解析锁。首页 `HomeCourses` 异步读取当前日期至一个月的窗口，并按版本、日期和时区丢弃过期结果；关闭页面后丢弃回调。

- `python checks/timetable_check.py`：实际解析与布局回归。
- `python checks/academic_terms_check.py [本地ICS路径]`：学期边界、统计、分类、替换与保留、选择、删除、序列化、失败保留。使用实际业务代码、JSON 库，以及最小 Android 文件 API 替身；可选 ICS 参数仅本地读取，文件不提交到仓库。
- Android 设备上的导入日期选择、旋转、主题/大字体、浮窗触摸、完整备份恢复和覆盖安装仍需实机验收。
