# 已确认的交互基线

## 工作区条件操作

2026-10-27课堂四视图沿用原Dock参数；窄屏大字放不下时原位改用当前视图与公共选择面板。仅「监视」视图在刷新右侧合入运行设置，共用48dp单元、1dp分隔、整组1.10倍按压。设置退出按EXIT渐隐缩小并收起按钮与分隔宽度，进入按ENTER恢复，反向从当前进度继续；隐藏开始即禁用触摸与无障碍入口，脱离收敛到目标，减少动画时直接落位。其它视图仅有刷新，不留设置空槽；本地读取不改变刷新图标，实际远端刷新才显示取消X。列表末尾与专用页不再放设置。专用监视页正常高度保留完整底部motion host，短窗口复用纵向Dock侧栏；首尾长按、拖出及惯性包络不变，回最新与末尾留白按当前导航位置及实测包络定位；右上「后续课程」不重建阅读或连接。

课堂子页首次呈现复用`UiMotion.enterPage`的240ms、8dp、SETTLE，在首次布局绘制就绪后启动，避免冷启动或窗口变化耗尽尚未可见的入场时间；四视图与分页复用220ms方向快照过渡，快速反向接续当前合成画面。恢复和轮询不重播入场，离开清理ghost、位移及回调。分页使用持久`DateIntervalBar`，支持箭头、左右滑动、点击选页；搜索、Dock和页码栏不重建。减少动画时直接呈现目标，图片手部拖动仍跟随。

课堂列表的搜索输入框固定在列表滚动区上方，查询更新只替换列表，保留输入控件与焦点；筛选完整本地目录的可见范围后分页。历史排序字段与升降箭头同排，切换后对全部历史排序再回第一页；切视图、返回详情及recreate保留查询和排序。上述变化不调整公共Dock动效。

课堂字幕首次进入可定位最新；后续追加和句内修订保持当前滚动偏移，不自动拉到末尾。用户点击「回到最新」才执行新的末尾定位。触摸浏览、切换PPT再返回及页面重建均保留阅读位置，异步布局恢复不得覆盖用户的新滚动操作。

「回到最新」与右上开始／停止共用48dp单元、1dp分隔及1.10倍整组按压；字幕未到底部时按ENTER展开，回底或切到PPT按EXIT收起。显隐从当前进度接续，隐藏开始即停用触摸与无障碍，减少动画直接落位；标题动作宿主自适应48／97dp，不重建正文或挪动滚动位置。

条件动作收起为单按钮后，公共高光随当前完整表面重新裁切，左右圆角对称；再次展开及半途反向继续沿当前宽度更新。父胶囊宽度变化时同时使固定宽度子按钮的高光缓存失效，避免保留旧双按钮的半边遮罩；不调整Dock弹簧或运动包络。

字幕／PPT正文切换使用公共内容动效，底部选择栏保持实例；PPT容器随原图比例贴合宽度，图片零内距铺满，只保留一层公共圆角，不裁切文字或拉伸。PPT控制复用 `DateIntervalBar` 的箭头、点击选择及左右拖动，图片区域方向一致，不能误触工作区切页。内嵌图片与已有全屏图片页均在MOVE期间实时跟手，邻图随拖动进入，松手才定页或回弹；短拖取消、多指操作和首尾不越界。大图放大后优先平移，点击实际变换后的图片边界外空白关闭，图片内点击不误关，保留双击、双指缩放与保存。新图准备后连续衔接，不先清成空白；系统减少动画时保留手势跟随，松手直接呈现目标状态。

课表切到导入来源时，公共标题栏刷新图标按 `UiMotion.EXIT` 渐隐缩小并收起宽度和右侧间距；切回学校来源按 `UiMotion.ENTER` 恢复，反向操作从当前进度续接。退出开始即停止点击及无障碍聚焦，系统关闭动画时直接落到最终布局。此变化不修改选择栏弹簧、放大或惯性参数。

本页保存 2026-10-17 用户确认的选择栏手感，以 **0.15.18** 的公共实现为基线。通用设计原则见 [UI 规范](ui-style-contract.md)，业务操作见对应功能文档。未经用户重新明确授权，不调整这些效果；性能优化保持同样画面和行为。

连续图片手势接续已提交的目的页与当前像素位置；相邻图覆盖原图时仍保留整个图片视口的触摸流。箭头及选图也使用同一图片轨道动画，快速连续箭头按进行中的目的页递增；待解码图片准备好后切换，不阻断后续操作。沿用公共回弹时长与曲线。

专用监视阅读页以课程名作唯一标题；标题下12sp时间／地点与连接数量按2dp行距集中在左侧，右侧12sp「后续课程」保留48dp热区。普通窗口底部motion host采用与工作区相同的系统安全区+4dp宿主基线，保留完整运动包络，正文延伸到浮动栏下；不叠加二级表单末尾28dp。短窗口沿用侧边Dock与可滚动信息区。

所有图片入口的大图横屏统一隐藏系统状态栏及标题，媒体视口铺满整个窗口并延伸到摄像头区域；返回／保存采用公共48dp图标，仅操作遵循安全区左右20dp、顶部16dp。系统临时栏按系统手势控制，保存返回后重新隐藏状态栏，离开查看页恢复正常系统栏。缩放始终沿焦点计算，不在100%重置居中；放大平移先消费到边缘，剩余横向拖动进入原图库跟手轨道，使用原翻页阈值、回弹与减少动画设置。

## 选择栏的完整操作过程

图片附件、课堂大图与内嵌PPT使用系统长按阈值提起当前已显示图片；拖影最长边160dp、保留比例并使用公共卡片圆角。不改原有翻页与缩放阈值，翻页中、移动或多指时不提起；提起后由系统接管，取消或完成后的下一次触摸正常恢复。拖放只授予精确图片URI的临时读取权限，接收应用决定是否接受图片。

横屏或短窗口的正文纵向嵌套滚动先连续收起顶部工具，并按实际收起量扩大正文，回顶下拉恢复。双向网格保留横滑、边缘周切换、捏合及原离手速度；工具的测量探测阶段不改变已收起位移。编辑键盘显示时保留输入区。Dashboard侧Dock与竖屏统一8dp左右、6dp上下内距，选项左右4dp、上下0；纵向底板按内容自然高度，不以固定290dp留下不对称尾空白。父布局允许原高光与整栏放大超出底板，不改变弹簧参数。

Dashboard横屏侧栏宽104dp，78dp底板居中；首页与切页副本均保留20dp正文左右内距，底板到正文的静止间隔为33dp。不再按屏幕宽度额外居中正文列；外侧空位与底板内距分别核对，不能靠缩小按钮代替收紧间隔。

按下即朝目标连续移动并快速放大，无需等待长按。持续持有时高光为 1.5 倍、整栏为 1.1 倍；短按保留较小脉冲。拖动中高光前沿先行、尾部追随，高度平滑变为 95%，到位后恢复。大小、位置、宽度和覆盖颜色均连续变化，文字和图标不随高光拉伸，圆角按实际形状保持。

松手从当前画面继续，直接继承离手实测速度，不设速度上限、不统一减半；移动、惯性、尾部及归位使用正常时间。缩小响应时长为放大的 1.5 倍，取消或系统关闭动画不补播脉冲。普通点击平稳收敛，远距离点击不在目标附近振荡；惯性越界与点击归位分开处理。

高光可部分超出轨道，以连续边缘阻力和较快回弹限制伸出，不能改为框内裁切、向内挪动或压缩形状。预测落点和实际运动共用积分。浮动轨道可向触点轻微偏移，释放后回中；全宽表单轨道不水平偏移。

纵向浮动菜单行取消独立按钮表面和缩放，仅保留整行涟漪；选项以细分隔线区分，主题色与尾部勾选表达选中。公共浮层开合动效及 Dock 交互保持不变。

2026-10-20 用户确认标题槽与日历全宽选择栏优先保持原有样式和选项均匀铺开；极端甩动允许高光出屏，交付时说明。不得增加内部轨道边距把文字集中到中间，也不收紧最大越界或修改弹簧参数；静态内距和页面内部裁切仍需检查。

## 主页导航与快捷按钮

新作业定位使用 8dp 红点，中心位于作业图标中心右上各 9dp。定位行使用当前卡片圆角、2dp 主题色边框及浅主题色填充，停留一个 `UiMotion.ENTER` 后在 2000ms 内渐隐；系统关闭动画时保持强调 2000ms 后直接恢复。目标按实际滚动视口居中；首尾行只补足本次定位所需的真实滚动空间，滤镜或分页变化即移除。此动效不修改 Dock、胶囊或卡片按压参数。

主页及日历／周日程的系统日程开关启用时只改变图标颜色，不增加选中背景；按压复用同组按钮的公共填充高光，不绘制独立圆形涟漪。切换仍保留连续图标色彩反馈、原生开关状态、点击区域与整组放大。

「＋」仅首页显示。切换到日程／收件箱时，Dock 整体居中、适度增宽，默认 230ms；「＋」独立缩放、渐隐并模糊退出，至少 460ms，使用非线性缓入缓出。返回首页保持现有节奏，宽屏侧栏不随快捷按钮扩缩。导航文字按实际宽度布局，不横向拉伸。

按钮模糊采用透明边缘采样，最大 18dp 模糊、四边 36dp 绘制余量，不延伸实际触控区。页面提交不提前截断按钮动画；反向、取消和拖动接管从各自当前进度接续，隐藏或切换中的按钮不响应点击与无障碍焦点。

## 修改后如何核对

2026-10-26用户决定移除胶囊无障碍服务及点击后60秒延长。新提醒、亮屏和退出拾时进入后台时，胶囊完整展示30秒，随后只保留标题前两个字和图标；完整卡片不截断标题。应用内部跳转及配置重建不续期，普通及秒级刷新不续期；点击胶囊也不重置期限。展开和点空白收回始终由系统控制，不强制开关。只使用本应用生命周期与亮屏广播，不监听其它应用窗口，因此从其它应用回到桌面不具有单独触发保证。作业十分钟存续、完成／关闭及主页红点不变。历史30／60秒证据仅用于追溯旧版本。

任务详情溢出菜单使用Lucide `ic_ellipsis_vertical`与48dp热区，复用`HeaderActionGroup`，整组按压放大1.10；实际DOWN/UP打开菜单并回落，取消动作同样回落。重复日程弹窗默认不选，勾选只改变本批组选择与提交计数，不直接修改候选；提交时冻结选择与来源操作，公共浮层开合参数不变。

当前用户固件从大卡片收起时经约200ms系统固定窄态再进入实际胶囊宽度；应用不改宿主或全局动画。移除点击计时不改变这段系统过渡。临时测试变体仅将保留的30秒窗口缩为5秒，正式包仍为30秒。

网页版记录详情采用主从布局：桌面列表／详情约30%／70%，窄屏在两者之间切换。取消横向卡片轨道、卡内长文滚动及底部事项选择器，完整详情随页面滚动。列表使用主题边线和底色表达当前项，状态保留文字／图标，过期与即将截止分级强调，完成项后置；外部candidate_id直接选中，键盘上下／Home／End可切换。编辑在详情区原位展开，保存／取消保持在Dock上方可达；150%文字时操作按钮自然换行，不挤成竖排。公共弹窗只有真正遮罩的完整点按关闭，内部空白和内外拖动不误关；关闭热区48px，系统减少动画时直接完成状态切换。

连续打开／关闭浮层、退出中立即重开时，背景从当前画面接续，始终沿用本轮最初缩放基准；最后一个浮层退出后恢复该基准，不累计放大。减少动画、页面结束及视图脱离时立即恢复并清理状态。实现入口为 `UiDialogs`，库整理不改变既有放大幅度及开合时长。

核对首尾按压、远距离点击、双向快速甩动、越界回弹及半途反向的实际画面，关注连续性、圆角和内容可读性。历史参考视频与旧调参仅用于追溯，不能覆盖本基线。各版本的实际检查及性能数据见 [验证记录](validation-history.md)。
