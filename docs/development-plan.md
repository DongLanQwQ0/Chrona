# Chrona 历史收尾计划（已完成）

下列计划对应早期类型、全天和界面开发，相关功能已经实现，保留为历史背景。当前维护事项与执行结果见[软件审查与完善清单](quality-audit.md)，不要把本页当作尚未完成的任务列表。

依据 `HANDOFF.md` 与 `README.md`，保持现有文字、图片、语音、异步解析、审核和系统日历闭环。通用开放式搜索继续暂缓；不增加依赖或更换工具链。

1. 为日程草稿增加类型与全天标记，按数据库版本顺序迁移既有数据。解析结果允许缺少新字段，旧数据默认为“活动”和非全天。
2. 在详情页编辑类型与全天日期，全天事件以 UTC 零点和排他的结束日写入 Android 日历；保存与再次打开时保持日期一致。
3. 首页提供历史筛选与可滚动布局；详情和设置页统一视觉样式，给进入、状态变化、点击反馈增加适度动画，并尊重系统减少动画设置。
4. 增加与新字段和日期转换有关的离线验证，运行 `assembleDebug`，检查实际 diff，更新产品文档与版本号。

验收重点：旧数据库升级后原行不丢失；跨时区和跨天的全天日程日期正确；权限拒绝时不产生半写入；旧服务未返回新字段时解析仍可用；小屏和大字号下全部操作可滚动访问。
