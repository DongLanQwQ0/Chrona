# 桌面小组件与记录草稿（0.13.54）

- 桌面长按 → 小组件 → 拾时：可添加「下一件事」和「今天的安排」。尺寸可调整，今天列表可滚动。
- 标题打开主页，日程打开详情（系统事项打开系统日历），＋打开文字/图片/文件记录，刷新按钮手动更新。没有语音入口。
- 0.13.55：允许缩至单格，由启动器决定具体格数。窄/短尺寸优先标题与开始时间，中大尺寸展示地点和列表；Android 12+ 根据启动器提供的实际尺寸交付多个布局，旧系统缩放后刷新。
- 背景复用应用壁纸、模糊算法与强度；壁纸透明图层叠加主题色，再由桌面合成。主题色混合比例跟随外观设置；无可用壁纸时使用半透明主题色。
- 标准 RemoteViews 没有通用接口模糊其背后的启动器内容，因此不会读取或截图桌面，也不承诺桌面实时背景模糊。
- 日程来源跟随主页的「包含系统其他日程」，过滤已关联系统事件，避免重复显示。查询未来一个月；单次本地查询与今日列表上限 200 条，不加载整个历史。
- 本地数据修改、主题/来源变更、返回主页和进程存活时的系统日历变更触发合并刷新。系统定期更新间隔为 30 分钟，也可手动刷新；不承诺锁屏/省电时精确切换正在进行的状态。
- Android 12+ 使用直接 RemoteCollectionItems；Android 8–11 使用 RemoteViewsService。
- 记录退出提供「保留草稿 / 放弃 / 取消」。草稿文字与附件引用保存在本机私有存储，提交成功后清除；保留的照片不会被孤立图片清理删除。
- 普通文件仍按原机制保存在公共 Downloads/Chrona，放弃只删除草稿引用，不删除公共副本。
- 导入期间禁止退出/提交；旋转时保留同一导入会话。草稿不自动发送给 AI，也不新增云服务。
- 验证范围：编译、lint 和本地数据检查。桌面布局、滚动和不同厂商启动器行为仍需真机验收。
