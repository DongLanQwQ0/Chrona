# 收件归档与待办完成实施计划

**目标：** 实现大量日程浏览第二轮：已处理收件归档/恢复，待办完成/撤销。

**架构：** `tasks.archived` 和 `event_candidates.completed` 独立保存，不改解析状态枚举或系统日历。专用 setter 管理状态，普通内容编辑保留完成标记；待办转为其他类型时清除标记。沿用卡片、分页、筛选动画及多选操作。

**边界：** 仅已处理（ready）收件可归档，原文、模型输出、附件、日程均保留。完成仅针对待办，不从过期时间推断，不删除或停用系统日历提醒。重新解析仍替换草稿，新候选默认未完成。
