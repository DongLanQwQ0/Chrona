# 大量日程浏览实施计划

**目标：** 完成已确认的第一轮：按日期分组、日期跳转、组合筛选和真正分页。

**架构：** 复用 DashboardActivity 卡片与自绘日期选择器；用纯 Java 查询条件对象组织参数化 SQL，TaskStore 在数据库完成筛选、排序、计数与每页 24 项查询。系统来源使用可取消的有界 Instances 查询，保持只读；不增加归档或待办完成状态。

**约束：** Java 17 / minSdk 26；不新增依赖、云服务或手机操作。选择与日期窗口保存在页面状态中；全部筛选 ID 查询只返回 ID，批量操作语义不变。旧数据库和 ZIP 备份可迁移。

## 步骤

- [x] 写查询回归检查：同一时间稳定分页、空时间、状态与类型组合、搜索通配符、全天 UTC 边界、区间相交。

## 风险核验

日期窗口使用当地普通日程边界和 UTC 全天边界；翻页后同一 ID 不重不漏；空时间事项保留在「待安排」；筛选变化回到第一页；全选不局限当前页；系统日程不进入删除流程。系统来源默认查询当前月份，日期跳转或范围筛选可调整窗口，读取上限明确显示。
