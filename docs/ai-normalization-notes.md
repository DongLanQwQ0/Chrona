# AI 时间规范化与候选规则实施记录

本次范围：SemanticEventNormalizer、CandidateRules、ProcessingJobService 和离线检查。

1. 语义 JSON 转换为现有 EventCandidate，保留旧毫秒输入；程序负责日期、时区、全天边界、默认时长、截止与提醒。矛盾、缺失或非法时间保留草稿并标记待确认。
2. 严格比较全部业务字段去重；删除基于同时间的合并；活动时间重叠保留并标记待确认。
3. 请求重试共用固定时间和时区；结构/截断响应错误不自动再次收费请求，保留网络重试。
4. 纯 Java/JSON 检查覆盖语义日期、默认与显式时长、截止提醒、旧格式、严格去重和冲突。根代理统一执行 Gradle。
