拾时是一款 Android 日程助手，帮你把通知、聊天和截图里的安排整理成日程，集中查看并按时提醒。

## 主要功能

- **AI 整理**：从文字、截图和分享内容中提取日程；明确的安排自动写入，存疑的时间给出建议，由你确认。
- **日程管理**：管理活动、待办、作业和重复安排，支持多视图日历、提醒与桌面小组件。
- **课表与教务**：导入 ICS 课表；通过「折姜星辰」获取浙大作业、课表及考试时间、考场和座位。
- **课堂学习**：监视实时字幕和 PPT，课后补全资料并生成 AI 笔记，支持批量下载、导出。
- **跨设备查看**：在局域网浏览器中使用首页、日程和收件箱；多台 Android 设备可通过 WebDAV 同步。
- **数据管理**：保留原文、附件和时间解析依据，支持备份与恢复。

## 开始使用

1. 下载并安装 [最新 APK](https://github.com/DongLanQwQ0/Chrona/releases/latest)。更新时直接覆盖安装，保留原应用。
2. 如需 AI 整理，在「设置 → AI 服务」填写自己的服务地址、模型和 API 密钥。
3. 点首页 **＋** 输入文字或添加截图，也可从其他应用分享内容；在「收件箱」核对结果，在「日程」查看和修改安排。

例如：

> 明天下午 3 点到 4 点，在图书馆学习，提前 10 分钟提醒我。

## 使用提示

- 提醒按需授予日历、通知及精确闹钟权限；具体设置见 [使用指南](docs/user-guide.md)。
- 解析时，相关文字和图片会发送给你配置的 AI 服务；原文和附件保存在本机，可自行备份。
- **支持的 vivo／iQOO 机型首次启用原子岛需 ADB 配置**：[一键配置包](https://github.com/DongLanQwQ0/Chrona/releases/download/vivo-setup-0.15.42/Chrona-vivo-setup-0.15.42.zip) · [配置说明](tools/vivo/README.md)。配置成功后，日常使用无需连接电脑。
