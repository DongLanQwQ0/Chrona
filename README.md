社团通知、聊天里的约定、截图中的截止时间，常常散落在不同地方。拾时帮你把这些内容整理成日程，让重要的事情有地方可查、到时间有人提醒。

**记下来 → 检查草稿 → 确认日程 → 系统日历提醒**

## 拾时能帮你做什么

| 功能 | 可以这样用 |
| --- | --- |
| **随手记录** | 输入文字、粘贴剪贴板、添加截图，或从其他应用分享内容给拾时。 |
| **一次整理多件事** | 一段内容可以生成多个日程；活动、待办、提醒、截止和备忘都能分别整理。 |
| **确认后再提醒** | 先核对和修改识别结果，补全不确定的信息，再写入系统日历。 |
| **随时查看安排** | 首页时间线、日程搜索与筛选、桌面小组件，让安排更容易找到。 |
| **按自己的习惯使用** | 支持浅色与深色、多种主题色、自定义背景，以及备份与恢复。 |

## 开始使用

1. 从 [最新版本](https://github.com/DongLanQwQ0/Chrona/releases/latest) 下载 APK 并安装。
2. 跟着应用内的六步引导完成准备；也可以查看 [详细使用指南](docs/user-guide.md)。
3. 点主界面的 **+**，记下第一件事。解析完成后，到「收件箱」检查并确认。

例如：

> 明天下午 3 点到 4 点，在图书馆学习，提前 10 分钟提醒我。

已经装过拾时？下载新版后**直接覆盖安装**即可，请保留原来的应用。也可以在「设置 → 检查更新」查看新版本。

## 使用前了解

- **需要自己的 AI 服务。** 拾时使用你配置的服务理解内容；图片识别需要支持图片的模型。配置方法见 [使用指南](docs/user-guide.md#配置-ai-服务)。
- **日程需要你确认。** AI 可能理解有误，尤其是模糊时间和多项安排。检查草稿后再写入日历。
- **提醒由系统日历负责。** 请允许日历权限，并开启系统日历的通知与提醒。
- **记录可以备份。** 收件箱和附件保存在本机；用于解析的文字和图片会发送给你配置的 AI 服务。备份与数据说明见 [使用指南](docs/user-guide.md#备份与数据)。
