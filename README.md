# 拾时 · Chrona

独立 Android 日程应用。首版闭环是：输入文字或通过系统分享文字 → 后台调用用户配置的 AI 服务 → 在应用内审核、修改日程草稿 → 写入专属的本地系统日历并由系统提醒。

当前版本：`0.5.0`。完整产品需求与历史决策见 [HANDOFF.md](HANDOFF.md)。

## 当前功能

- 应用内文字输入、Android `text/plain` 分享入口；每条输入先存入本地 SQLite 收件箱。
- 收件箱可一键读取剪贴板文字（追加到输入框，便于连续收集多条），并可勾选「按行拆分为多条」把整段粘贴按非空行拆成多条独立输入；每次最多拆分 20 条，避免一次产生过多付费解析请求。
- 图片输入：可从系统分享菜单接收图片，也可选择相册图片或截图；图片存入应用私有目录并缩放到长边 1568 px、JPEG 质量 90 后随请求发送。支持「只发图片」的输入。若服务拒绝带图片的请求，应用会判定该「地址 + 模型」不支持图片并停用图片入口，可在设置中重新启用。
- 语音输入：调用 Android 系统的语音识别界面，识别结果追加到输入框，可连续说几条再一次性提交。不申请录音权限、不调用云端转写接口；设备没有系统识别服务时该入口隐藏。
- 按需联网检索（输入含链接时）：解析前自动抓取链接正文作为上下文，用于补全网页上才有的时间、地点与报名信息。上限为每条输入 3 个链接、单页 512 KB、正文合计 4000 字，只接受 http/https；抓不到就按原文解析。任务详情显示抓取时间、字数与摘要，并提供「重新联网检查并解析」入口。
- `JobScheduler` 异步处理输入，网络可用时调用兼容 OpenAI Chat Completions 的自定义 HTTPS API；一次输入可返回多条草稿，记录服务返回的 token 用量。
- API 基础地址、模型名和密钥由用户填写。密钥以 Android Keystore 的 AES/GCM 加密后保存在本机；不要将真实密钥写入代码或文档。
- 日程草稿在应用内确认或修改后，写入应用专属的本地系统日历；支持继续在应用内更新已写入的日程。时间不完整的草稿不会自动写入。
- 日程删除：可逐条删除草稿（已写入日历的会同时删除系统日历中的对应条目），也可整条删除一次输入及其全部草稿；删除输入会取消仍在排队或运行中的解析。
- 解析结果通知与失败重试。日程提醒使用系统日历。

尚未实现：通用联网搜索（对模糊任务做开放式检索，需要第三方搜索服务）、历史分类、全天日程编辑及实际的提示词缓存统计。当前只统计 API 返回的 token 用量；图片支持与否只依据请求被拒的结果推断，没有权威的模型能力清单；语音转写质量取决于设备上的系统识别服务；链接抓取只做正文抽取，不执行页面脚本，重脚本页面可能取不到有效内容。

## 开发环境与构建

| 项目 | 当前配置 |
| --- | --- |
| Android Studio | `F:\Android\AndroidStudio` |
| Android SDK | `F:\Android\Sdk`，Android API 36 |
| Java | `D:\Minecraft\java21`，实际为 Java 22.0.2 |
| Gradle | Wrapper 9.6.0；缓存 `F:\Android\GradleCache` |
| Android Gradle Plugin | 9.4.1 |
| 应用 | Java 源码级别 17，`minSdk 26`，`targetSdk 36` |

用户已审核并批准上述 Gradle 与 Android Gradle Plugin 工具链。后续若需要**新增或更换构建工具链**，先提交具体方案供用户审核。项目路径含中文，`gradle.properties` 中的 `android.overridePathCheck=true` 已在当前环境中通过构建。

在 PowerShell 7 中构建：

```powershell
$ErrorActionPreference = 'Stop'
$env:JAVA_HOME = 'D:\Minecraft\java21'
$env:ANDROID_HOME = 'F:\Android\Sdk'
$env:GRADLE_USER_HOME = 'F:\Android\GradleCache'
.\gradlew.bat :app:assembleDebug --no-daemon --console=plain
```

产物位于 `app\build\outputs\apk\debug\app-debug.apk`，构建产物和本机配置已被 `.gitignore` 排除。Android Studio 可直接打开本目录。项目尚无远程 Git 仓库。

## 后续接力重点

1. 先读本文件、[HANDOFF.md](HANDOFF.md) 和 [CHANGELOG.md](CHANGELOG.md)，再查看对应模块代码；不要将历史需求当成已完成功能。
2. 收尾「通用联网搜索」（需先与用户确认第三方搜索服务），再补历史分类与全天日程编辑；文字、分享、剪贴板、批量、图片、语音与链接检索均已补齐。
3. 当前数据库版本为 3（`tasks.image_path`、`tasks.link_text`、`tasks.link_fetched_at`）。手机上的版本 1/2 数据靠 `TaskStore.onUpgrade` 的顺序 `ALTER TABLE` 保留；以后改表必须继续追加迁移，不能直接删库或只改 `onCreate`。
4. 真机回归至少覆盖：多个草稿、时间不确定、API 错误与重试、日历权限拒绝、已写入日程的应用内更新、删除后系统日历不再残留条目、剪贴板读取与按行拆分提交、**从 0.1.0/0.2.0/0.4.0 升级安装后既有数据仍在**、分享图片与选图、模型不支持图片时的降级提示、语音识别追加文字、含链接输入的抓取与「重新联网检查并解析」。
