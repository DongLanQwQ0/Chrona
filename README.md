# 拾时 · Chrona

Android 日程应用：记录文字、截图或系统分享内容，使用自己配置的 AI 服务生成日程草稿，审核后写入系统日历。

## 下载

从 [Releases](https://github.com/DongLanQwQ0/Chrona/releases) 下载最新 APK，安装后查看应用内使用引导。Android 8.0 及以上。

升级请覆盖安装，保留本机收件箱和设置。应用需要自行配置 AI 服务地址、模型及密钥；系统日历负责日程提醒。

## 版本更新

应用内「设置 → 检查更新」查看最新正式版、更新说明及下载入口。默认每天自动检查一次，可以关闭。

本仓库当前用作 APK 分发；源码暂未上传。每次 Release 会列出本次变更与实际验证情况。
