社团通知、聊天里的约定、截图中的截止时间，常常散落在不同地方。拾时帮你把这些内容整理成日程，让重要的事情有地方可查、到时间有人提醒。

**记下来 → 明确日程自动写入 → 存疑项由你确认 → 日程提醒**

## 拾时能帮你做什么

| 功能 | 可以这样用 |
| --- | --- |
| **电脑浏览器访问** | 手机设置中开启局域网访问，在同一网络的电脑浏览器配对，即可查看和修改手机日程、收件与课表，无需安装电脑客户端。 |
| **多设备同步** | 多台 Android 设备通过坚果云 WebDAV 同步日程、原文、附件和课表；并发修改保留版本供你确认。 |
| **本地课表** | 导入 ICS，按学年与春夏秋冬学期查看课程；常规课程进入周视图，特殊安排单独展示，可手动调整分类。 |
| **折姜星辰** | 设置中开启，直接读取学在浙大作业和教务课表；作业统一进入「作业」收件，截止变更保留记录，无需 AI。 |
| **随手记录** | 输入文字、粘贴剪贴板、添加截图，或从其他应用分享内容给拾时。 |
| **一次整理多件事** | 一段内容可以生成多个日程；活动与待办分别整理，提醒和截止作为属性，备忘保留在收件箱。 |
| **重复日程** | AI 可识别重复安排，也可手动设置；支持单次跳过、改期及待办完成，停止重复时保留历史。 |
| **课堂总结** | 从今天的安排进入智云课堂，先整理完整字幕，再按需分析最多 40 张图片；后台继续处理，可导出含图 Markdown ZIP。 |
| **课堂监视** | 顶部集中管理，专用页查看实时字幕和PPT、启停及勾选后续课堂；后台持续保存，下课后补齐完整资料。 |
| **明确日程自动确认** | 时间明确且模型肯定的日程自动写入并通知；模糊时间给出建议，标为高存疑待确认。 |
| **提前常驻提醒** | 开始前 30 分钟显示详细卡片，可查看、延后 5 分钟或隐藏本次。 |
| **随时查看安排** | 点收件箱标题打开年/月/周/日/日程日历；导入课表和浙大课表也可进入首页、小组件和提醒。全局选择日历来源，保留各页面的系统日程开关。 |
| **合并完全相同日程** | 设置中先扫描预览，再确认合并拾时的重复日程；原文、来源与附件保留，详情可追溯。 |
| **按自己的习惯使用** | 支持浅色与深色、多种主题色、自定义背景，以及备份与恢复。 |

## 开始使用

1. 从 [最新版本](https://github.com/DongLanQwQ0/Chrona/releases/latest) 下载 APK 并安装。
2. 跟着应用内的六步引导完成准备；也可以查看 [详细使用指南](docs/user-guide.md)。
3. 点主界面的 **+**，记下第一件事。通知会告知自动写入结果，存疑项到「收件箱」核对确认。

例如：

> 明天下午 3 点到 4 点，在图书馆学习，提前 10 分钟提醒我。

已经装过拾时？下载新版后**直接覆盖安装**即可，请保留原来的应用。也可以在「设置 → 检查更新」查看新版本。

## 使用前了解

- **需要自己的 AI 服务。** 拾时使用你配置的服务理解内容；图片识别需要支持图片的模型。配置方法见 [使用指南](docs/user-guide.md#配置-ai-服务)。
- **存疑日程需要你确认。** 模糊时间提供可修改的建议；完全明确的项自动写入并通知。
- **提醒需要系统权限。** 请允许日历和通知权限。提前常驻卡片的准时触发还需允许精确闹钟，系统日历原有提醒保留。
- **vivo 原子岛首次需要 ADB 配置。** 目前每台支持的 vivo / iQOO 手机都要用电脑配置一次，安装 APK 不会自动配置；成功后日常无需连接电脑。[下载一键配置包](https://github.com/DongLanQwQ0/Chrona/releases/download/vivo-setup-0.15.42/Chrona-vivo-setup-0.15.42.zip) · [操作步骤与兼容限制](tools/vivo/README.md)。
- **记录可以备份。** 收件箱和附件保存在本机；用于解析的文字和图片会发送给你配置的 AI 服务。备份与数据说明见 [使用指南](docs/user-guide.md#备份与数据)。
